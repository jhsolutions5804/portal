# 세션 로그 — 2026-09-16 (이어서 3) — 연차신청서 관리자 전 직원 조회 기능 추가

> 작성: 춘식이(Claude)

## 요청

대표님(스크린샷 2장) — ① 연차신청서 결재대기 상태인데 결재함에 안 뜨는 원인 문의. ② 연차신청서 화면에서 관리자 계정으로 들어가면 전 직원이 작성한 신청서를 조회할 수 있게 해달라.

## 진단 (①, 코드만 확인·미배포)

`DOC_CONFIG.leave`에만 `approvers` 배열이 없어(다른 문서종류는 전부 있음) `buildFixedApprovalLine('leave')`가 "작성" 단계만 있는 결재라인을 생성 — 결재자 자체가 없어 결재함(`loadApproveData`)에 절대 노출되지 않음. 수정안(김종화 총괄을 approvers로 지정) 제시 후 대표님 확답 대기 중, 이번 세션에서는 미반영.

## 구현 (②)

`fetchEdocDocs('leave')`가 관리자에게 이미 전체 문서를 반환하고 있었으나, 화면(`leaveRenderMyList`)이 권한과 무관하게 본인 작성분만 표시하던 것이 원인. `_isAdmin` 여부로 패널 제목·목록 소스를 분기(전 직원 조회 시 작성자명·직급 표기)하도록 수정. 별도 쿼리·권한 변경 없음. 상세: `7_37_log_edoc_leave_admin_view.md`.
