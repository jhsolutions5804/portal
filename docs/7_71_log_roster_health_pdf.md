## 1.6.1 날짜 입력 버그
- 원인: 날짜 칸에서 연도를 고쳐 쓰는 중간값(0002-… 등)이 유효한 날짜가 되어 change 이벤트마다 검진/자격 행 전체를 다시 그려 입력 칸이 사라지고 초기화됨.
- 수정: 다시 그리지 않고 만료일·상태만 제자리 갱신, 연도 1900~2100 밖의 타이핑 중간값은 계산에서 제외. 브라우저 키보드 입력으로 수정 전 재현·수정 후 확인.

## 1.7.0 검진 결과 PDF
- 저장소: Firebase Storage 버킷 `p4ph2-fab-506a7.firebasestorage.app` (서울 asia-northeast3, Regional — 국내 저장). 경로 `roster_health/<근로자ID>/<시각>_<난수>.pdf`.
- 메타(이름·크기·경로·업로드 시각)는 `master_worker_private.health[].pdf`(관리자 전용)에 저장.
- 화면: 검진 줄마다 📎첨부/교체/파일 삭제/다운로드, 목록의 검진 칸에 📄 결과 링크. PDF만·15MB 미만.
- 다운로드는 **다운로드 URL(토큰 링크)을 발급하지 않고** 로그인한 관리자 권한으로 직접 받아 저장(getBlob) — 주소가 유출돼도 열리지 않음.
- 저장 흐름: 업로드 실패 시 저장 전체 중단 / 저장 실패 시 방금 올린 파일 삭제 / 교체·삭제·검진 줄 삭제·근로자 삭제 시 옛 파일 정리.
- 보안 규칙(`storage.rules.txt`, 대표님이 콘솔에서 게시): `roster_health/**`는 승인된 @jhsol.kr 관리자만 읽기/쓰기(PDF만, 15MB 미만), 그 외 전부 차단. 게시 전에는 업로드가 거부되어 저장이 안전하게 중단됨.
- 테스트: UI 상태·오류 처리, 저장 로직 8개 시나리오(신규·교체·삭제·줄 삭제·유지·업로드 실패·저장 실패 정리·실시일 없음) 모의 Storage로 통과. **테섭에는 Storage가 없어 테섭 배포는 하지 않음**, 실제 업로드는 규칙 게시 후 본섭에서 확인 필요.
- 검진 만료 일정(`syncRosterExpiry`)은 PDF와 무관(결과·파일은 캘린더에 나가지 않음).
