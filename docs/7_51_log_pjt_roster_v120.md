# 개발로그 — 근로자 연명부 개정 v1.1.0 → v1.2.0

> 작성: 춘식이(Claude) · 2026-09-30 · 배포: portal-test (본섭 대기) — v1.1.0은 v1.2.0에 포함되어 함께 배포

## 요청 (대표님, 테섭 화면 캡처 기반)

1. 사내화 교육 이수 여부에 만료일을 함께 표시
2. 사진 파일을 사진·신분증·건설기초이수증 3칸으로 분리
3. 계좌번호·일당을 하나로 묶어 비고란 아래에 두고 관리자 전용 조회로
4. '기본정보'를 '인적사항'으로 바꾸고 전화번호를 여기에 포함
5. 자격·인증·사내화 교육·상생협력포탈 영역을 삼성전자 / SK하이닉스 2개 섹션(탭)으로 나누고, 자격은 각 탭에서 조회, 사내화 교육은 우선 삼성전자에만, 자격에 취득 현장명 입력

## 설계 결정

- 첨부 3칸: 같은 `master_worker_photos` 컬렉션에서 문서 ID 접미사(`__idcard`, `__cert`)로 구분 → 보안규칙 변경 불필요. 사진 칸은 기존 ID를 그대로 써서 호환. 메타는 `master_worker_private.files`에 통합하고 예전 단일 사진 필드는 읽을 때 승격·저장 시 비움.
- 일당은 월간 공수(팀 단가 집계)가 `master_workers.dailyRate`를 읽으므로 이동하지 않고 화면의 관리자 전용 구역에서만 편집. 데이터 수준 제한은 연명부를 비관리자에게 열 때 별도 작업.
- 원청 탭: `certs[].co`(`samsung`/`skhynix`). 구분 없던 기존 자격은 삼성전자로 간주. 사내화 교육·상생협력포탈 계정은 삼성전자 탭. 포털이 어느 원청 것인지는 검색으로 확인하지 못해 가정으로 배치(변경 용이).
- 교육 만료 판정은 자격과 같은 로직(`eduStateOf`): 만료됨 / 30일 이내 임박 / 유효. 요약 카드의 "미완료·만료"는 4종 미이수 또는 만료 1건 이상.
- 자격명 없이 취득 현장·날짜만 입력된 행은 저장 시 데이터 손실 방지를 위해 차단하고 해당 탭으로 이동.
