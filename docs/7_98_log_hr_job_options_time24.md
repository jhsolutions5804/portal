# 7.98. 개발로그 — 공고 입력 선택지 + 시간 입력 24시간 통일 (hr 2.27.0, 본섭)

> 2026-10-01 · 춘식이(Claude) · 대표님: "경력·학력·고용형태·근무일시를 통상적인 구인 공고 옵션으로 선택하게, 고정하지 말고" → "포털의 모든 시간 입력을 24시간 포맷으로" → 테섭(hr 2.29.0·2.30.0) 확인 후 "본섭 적용해"

## 변경
- `hr/index.html` 공고 관리: 경력(경력무관/신입/경력/신입·경력+연차), 학력(무관~박사+이상·졸업예정자), 고용형태(복수선택+정규직 수습·계약직 기간·전환), 근무일시(요일+시간+협의)를 선택지로. 선택값은 홈페이지 표시 문장으로 조합해 기존 필드(career/education/empType/workTime)에 저장, 선택값은 `opt`에 보관 → 홈페이지 파일은 수정 불필요. 옛 공고는 수정 화면에서 문구로 선택값 추정. 고용형태에 '파견직'은 제외(도급과 법적 구분 혼동 방지).
- 공용 `time24.js` 신설(`0_7_portal_time24.md`), 7개 화면에 태그 삽입. 면접 일시 datetime-local → 날짜+24시간 두 칸.
- 본섭 번호 2.27.0(테섭은 2.29.0·2.30.0로 나뉘어 있음 — 본섭엔 둘을 한 번에 반영).

## 검증
- 본섭 파일 그대로: JS 문법, 공고 폼(기본값·조합 문장·저장), 면접 일시(날짜만→보류, 둘 다→저장, 날짜 지움→해제), 7개 화면 로드(오류 없음, 변환 확인), 본섭 버튼 URL이 홈페이지 본주소. 반영 후 portal.jhsol.kr에서 hr 2.27.0·time24.js(200)·7개 화면 태그 확인.
- 테섭 단계에서 발견·수정: 근무일시가 빈 값으로 덮어써지던 저장 오류, 옛 공고 경력 연차 복원 오류, 콜론 포함 입력의 확정 값 불일치(200→02:00).

## 참고
- 테섭 파일 통째 복사 금지 원칙에 따라 본섭 hr·화면은 독립 패치. 출퇴근 기록(attendance)은 본섭에 없어 제외.
- 로그인이 필요한 화면(전자결재·업무일지·모바일)의 시간 칸은 로그인 상태로 직접 확인 필요(대표님 확인 요청).
- 문서 번호 충돌 회피: 0_6은 다른 세션의 portal_home_widgets가 사용 중이라 0_7로 작성.
