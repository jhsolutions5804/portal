## 구현

### 1~2. 하단 작업탭 서브탭 단위 분리
처음엔 탭 라벨만 서브탭 이름으로 바꿨는데(`SUBTABS[m.key].find`), 대표님이 "기획>프로젝트, 기획>견적처럼 각각 별도 탭으로 열려야 한다"고 명확히 해 전면 재설계. 탭 id를 `sub:<모듈key>:<서브탭key>` 단위로 바꾸고, 이미 열린 서브탭은 재사용, 없으면 새 iframe(`?tab=<서브탭key>`)을 만든다. 임베드된 앱(edoc/hr/gihoek) 내부 이동도 `postMessage`로 포털에 알려 탭 라벨을 실시간 동기화(`e.source`로 정확한 탭 특정). 상세: `0_5_portal_tabs.md`.

### 3~4. 포털 홈 위젯 개편
Outlook OAuth2 카드(및 관련 헬퍼 전부) 제거 → 출퇴근 기록(전자결재와 `worker_attendance_log` 공유) + 업무일지(오늘 작성여부·최근목록, 클릭 시 이동) 두 위젯으로 교체. `.home-dash` 3열 그리드, 카드 `min-height:300px` 고정 + 목록 스크롤(`.approve-list`/`.outlook-mail-list`). 홈 하단에 "전체 PJT 일정" 캘린더 신설 — PJT 홈의 기존 캘린더와 데이터 소스(FAB/SUP/경량PJT)는 같지만 완전히 독립된 상태로 구현(상태 충돌 방지). 상세: `0_6_portal_home_widgets.md`.

### 5. 회사 일정
`PJT_SCHED_COL`에 `company:['company_schedules']`, `PJT_SUBTABS`에 `회사 일정` 항목 추가 — 기존 일정 등록 폼·계산 로직을 전혀 건드리지 않고 "그냥 프로젝트 하나 더" 취급으로 흡수. 단, PJT 사이드바·카드 목록엔 노출되면 안 되므로 3곳에 `company` 제외 필터 추가. 홈 캘린더 날짜 상세에 "＋ 일정 등록" 버튼도 추가해 홈에서 바로 등록 가능. 상세: `0_6_portal_home_widgets.md`.

### 6. 새로고침 시 탭 초기화
`jhRestoreTabs()`(로그인/새로고침 시 1회 호출)를 "세션 복원"에서 "탭 목록·sessionStorage 완전 초기화"로 동작 변경. 상세: `0_5_portal_tabs.md`.

### 7. 연봉·근로계약서 목록 복귀 버그
상세화면의 "‹ 목록" 버튼이 아무도 진입하지 않는 옛 조회 화면(`renderAnnualList2`/`renderLaborList2`)으로 가던 버그. 실제 진입 경로인 메인 목록(`renderAnnualMain`/`renderLaborMain`)으로 수정. 상세: `2_2_hr_labor_annual_r3.md`, `2_3_hr_annual_r2.md`.
