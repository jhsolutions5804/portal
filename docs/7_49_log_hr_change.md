# 개발로그 — 인사 변동 메뉴 신설 (hr 2.14.0)

> 작성: 춘식이(Claude) · 2026-09-30 · 배포: portal-test (본섭 대기)

## 요청 · 결정 경과

1. 인사 개편 후속 점검 요청 → 코드 점검 결과 5단계 중 "변동" 단계가 화면 구조에 없고, 승진·이동·연봉조정이 명부 수정과 계약서 재작성으로 흩어져 있음을 확인.
2. 대표님 결정: 퇴사 후속 서류(재직/경력증명서, 4대보험 상실)와 입사 체크리스트는 불필요(원청 PJT 포털에서 처리), 현장 배치 변경도 제외. **변동처리(직급·부서·연봉)만 진행.**
3. 대기열 4번(포괄/비포괄임금제 선택)은 이미 구현되어 있음을 확인(`wageType`) → 정리 대상.

## 설계 중 조정

- 연봉은 근로계약서의 시급/월급/연봉 입력에서 산정되어 연봉계약서로 이어지는 구조 → 변동 화면에서 연봉 금액을 미리 채우지 않고 **근로계약서 작성으로 연결**(근로자·시작일·종료일만 프리필). 서명 문서는 자동 생성하지 않음.
- 연봉 이력은 이중 기록 없이 저장된 연봉계약서의 계약연봉 변화에서 산출.
