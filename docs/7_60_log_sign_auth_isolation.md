# 7.60. 개발로그 — 서명 페이지가 포털 로그인을 지우는 문제 수정

> 2026-09-30 · 춘식이(Claude)

- 증상: 같은 브라우저에서 서명 링크를 열거나 서명한 뒤 포털로 돌아오면 권한이 사라짐("포털을 통해 접근해주세요").
- 원인: `sign.html`이 Firebase 기본 앱을 사용해 포털과 같은 인증 상태를 공유. 링크 진입 시 `auth.currentUser`(포털 로그인 사용자)가 있으면 `signOut`을 호출했고, 이어지는 전화 로그인이 세션을 덮어씀.
- 수정: `initializeApp(firebaseConfig, 'sign')` — 별도 이름의 앱으로 인증 상태(저장 키)를 분리. 서명 페이지의 로그아웃·전화 로그인이 포털 세션에 영향을 주지 않음.
- 이미 로그아웃된 브라우저는 포털에 한 번 다시 로그인 필요.
