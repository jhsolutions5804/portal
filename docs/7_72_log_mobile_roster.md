## 추가 반영 (연명부 1.8.0 · 모바일 연명부 1.1.0)
- 검진 결과 PDF를 검진 줄 **같은 줄**에 배치: `📎 PDF` 버튼 → 첨부 후 `📄 파일명(잘림) ⬇ ↻ 🗑`. 날짜 칸은 그룹(`.hdates`)으로 묶어 폰에서는 3줄 카드로 정돈. PC(1000·1280px)에서 한 줄·겹침·넘침 없음 측정 확인.
- **모바일에서도 PC와 같은 수정·등록 화면**: PC 페이지에 모바일 모드(`?m=1&edit=<id>` / `?m=1&new=1`)를 추가해 같은 폼을 전체 화면으로 재사용 — 필드·검진(+PDF)·자격·교육·파일·금액·삭제 모두 동일, 이후 PC 수정도 모바일에 자동 반영. 닫기/저장 후 모바일 연명부로 복귀.
- 모바일 연명부: ＋ 신규 등록, ✏️ 수정, 퇴사처리/재직 전환(팀장 보호 포함, PC와 같은 규칙).
- 남은 차이: 기존 인원 마이그레이션(PC 관리 도구)은 PC 전용.

## 연명부 1.9.0 · 모바일 연명부 1.2.0 — 목록 정렬
- PC: 목록 머리글(이름·성별·주민등록번호·전화번호·입사일·소속·일반검진·배치전검진·사내화 교육·자격·인증·첨부)을 누르면 **오름차순 → 내림차순 → 기본 정렬** 순으로 바뀜. 활성 머리글은 ▲/▼ 강조, 나머지는 ↕ 표시.
- 값이 없는 사람(입사일·전화·성별·검진 기록 없음)은 방향과 관계없이 **항상 맨 아래**. 같은 값이면 이름순.
- 검진 정렬은 만료일 기준(곧 만료되는 순), 교육은 이수 개수, 자격·첨부는 등록 개수, 소속은 팀장/독립 먼저 → 팀장 이름순. 정렬 중에는 퇴사자도 전체 정렬에 포함(전체 보기 시).
- 모바일: 목록 위 정렬 선택(기본·이름·성별·입사일·전화·소속·검진 만료·교육·자격·첨부) + ▲/▼ 방향 버튼, 기본 순서도 PC와 같이 팀장→팀별→이름.
- 검증: 6명(빈 값·퇴사자 포함) 데이터로 전 항목 오름/내림/기본 복귀, 전체 보기, 모바일 선택 동작 확인. 날짜 입력 회귀 테스트 통과.
