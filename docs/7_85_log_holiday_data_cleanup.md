# 7.85. 개발로그 — 공휴일 데이터 정비 (2025~2027, 본섭 반영)

> 2026-10-01 · 춘식이(Claude) · 대표님 지시: "일단 본섭 반영먼저 하고 다음 거 하자"(테섭 정비 보고 후)

## 배경(발견)
- 포털 안에 공휴일 목록이 **화면마다 따로** 하드코딩돼 있고(9곳), 서로 다르며 오류·누락이 있었음.
  - 누락: 2026 노동절(5/1, 공휴일법 개정으로 2026부터 법정공휴일)·부처님오신날(5/24)·토요일 공휴일(광복절 8/15·개천절 10/3), 2025 임시공휴일(1/27)·대체공휴일(삼일절 3/3, 추석 10/8)·대선일(6/3), 2024-10-01(국군의 날 임시공휴일), 2027 대부분(설날 연휴·노동절·제헌절 및 각 대체공휴일 등).
  - 오류: 2027-02-10을 설날 연휴로 넣어둠(실제 2027 설날 연휴 2/6~2/8, 대체 2/9).
  - 모바일 전자결재(`m/edoc.html`)는 2027년 데이터가 통째로 없었음.

## 기준 데이터
- 2025~2027: 공휴일법(2026 노동절·제헌절 공휴일 지정, 대체공휴일 확대) 반영 — `holidays` 라이브러리(KR)와 웹 검색으로 노동절·제헌절 개정 확인. 2024-10-01 국군의 날(임시공휴일) 별도 추가.
- 2028년 이후는 정부 월력요항 발표 후 추가해야 함(임시공휴일·선거일은 사전 확정 불가).

## 변경 파일(본섭 8개 / 테섭 9개: 근태는 본섭 미반영 모듈)
`index.html`(PJT_CAL_HOLIDAYS) · `pjt`·`pjt_light`·`pjt_ph4`(HOLIDAYS) · `daily-report`(HOLIDAYS) · `edoc`(EDOC_KR_HOLIDAYS) · `m/edoc.html`(EDOC_KR_HOLIDAYS_M) · `hr`(KR_HOLIDAYS, hr 2.24.3) · (테섭 `attendance` KR_HOLIDAYS)
- 파일별 데이터 시작 연도 이후만 보충(데이터가 2026부터인 파일은 2026~2027). 이름이 있는 목록은 `'날짜':'이름'`, 날짜 Set은 날짜만 추가. 기존 항목은 삭제하지 않고(2027-02-10 제외) 누락분만 파일 끝에 `/* 2026-10-01 공휴일 정비 */` 주석과 함께 덧붙임.
- 각 파일 첫 줄에 `<!-- holiday-data: 20261001 … -->` 주석 추가(hr은 버전 주석 2.24.3).
- 정비 도구: 테섭 작업 중 `patch_holidays.py`(적용)·`verify_holidays.py`(실제 평가해 기준과 대조)로 반복 가능하게 처리.

## 검증
- 파일을 실제로 평가(Set/객체 → 날짜 목록)해 기준과 대조: 빠진 날짜 0, 중복 0, 2027-02-10 제거 확인, 기준 밖 날짜는 근태 모듈 3건(아래)뿐. JS 문법 오류 0. 변경 줄은 공휴일 데이터·버전 주석에 한정. 본섭 파일에 테섭 설정 혼입 없음.
- 본섭 라이브 확인: 반영 후 각 화면 파일에서 `holiday-data` 주석·`2026-05-01` 포함·`2027-02-10` 부재 확인.

## 영향(주의)
- 공휴일이 늘어 연차신청서 일수 계산(공휴일 제외)과 인사의 휴일근로·초과근무 판정이 해당 날짜에서 달라질 수 있다. 이미 저장된 문서·명세서의 금액은 불변. 예: 2026-05-01(노동절) 근무 기록을 다시 계산하면 휴일근로.

## 알려진 사항
- 테섭 근태(`attendance`) KR_HOLIDAYS에 공식 공휴일이 아닌 2026-02-19·02-20·09-28이 있음 — 회사·현장 지정 휴무일일 수 있어 유지(대표님 확인 대기).
- 공휴일 데이터가 9곳에 흩어져 있는 구조 자체는 그대로. 한 곳으로 모으는 작업(공용 파일)은 별도 과제.
