# 7.95. 개발로그 — 인사 근로시간 현황에 초과근로 시간·연장근로수당 집계 (hr 2.25.4)

> 2026-10-01 · 춘식이(Claude) · 대표님: "상단에 초과근로 얼마나 했고, 수당 얼마나 집계됐는지 표시… 근로시간 현황 섹션 하단" → 테섭(hr 2.26.1) 확인 후 "본섭"

## 변경 (`hr/index.html`, 인사 > 근로시간 > 근로자 상세의 '근로시간 현황' 카드)
- 카드 하단에 **초과근로 시간**과 **연장근로수당 집계** 추가. 급여명세서(`psCalcAll`)와 같은 기준:
  - 초과시간 = 평일 출퇴근 근무 + 유급휴가 − 해당 월 소정근로시간(≥0). 토·일·공휴일 근무는 제외하고 별도 안내(휴일근로수당으로 산정).
  - 수당 = 계약서 시급 × 초과시간 × 1.5. 포괄임금제 계약이면 고정 연장수당, 연봉계약서가 없으면 '—'.
  - 야간·휴일근로수당은 급여명세서에서 별도 산정(카드에 안내 문구).
- `otGetAttendanceSummary`에 평일/휴일 근무시간·`otPayHours` 추가, `otGetWage`에 `wageType`·계약 고정연장수당 추가.

## 검증
- JS 문법, 모의 계산(비포괄·포괄·계약서 없음·휴일근무). 본섭 최신 파일에 독립 패치(테섭의 공고 관리·계약서 v6 등 미반영 기능은 포함하지 않음), 설정 유지·테섭 설정 혼입 없음. 백업 `backup/v2.25.4/hr/index.html`(본섭), 테섭 `backup/v2.26.1/hr/`.

## 참고
- 본섭 버전 2.25.4과 테섭 2.26.1은 서로 다른 기능이 붙은 번호임(테섭에는 다른 대화의 미반영 기능이 있음). 본섭 반영 시 헤더를 각자 최신본 기준으로 갱신할 것.
