# 7.96. 개발로그 — 인사 공고 관리 신설 (hr 2.26.0, 본섭)

> 2026-10-01 · 춘식이(Claude) · 대표님: "공고관리 기능을 만들어보자… 채용 landing 페이지로 넘어가는 버튼" → "페이지 3개 다 버튼, 포털에서 공고 등록·수정·삭제" → 사람인 공고 양식 참고 → 테섭(hr 2.27.0·2.28.0) 확인 후 "본섭"

## 변경
- `hr/index.html`: 공고 관리 스텁 → 목록·등록·수정·마감/게시·삭제, 홈페이지 3페이지 바로가기, 새 공고 기본 문구(`JOB_DEFAULTS`). 본섭 번호 2.26.0(테섭은 다른 기능과 번호가 달라 2.28.0).
- Firestore 규칙(본섭): `job_postings` 추가(비로그인은 open 공고만 조회, 쓰기는 관리자).
- 홈페이지 레포: `recruit-jobs.html`·`recruit.html`·`careers.html` 교체(커밋 9d21212).

## 검증
- JS 문법(ESM), 가짜 DB로 등록·수정·마감·삭제·검증 흐름, 헤드리스 브라우저로 홈페이지 표시.
- 본섭 규칙 실서버 점검(비로그인 권한 7개 항목), 시험 공고를 본섭 DB에 넣고 운영 홈페이지 목록·상세·지원 링크·careers 공고 수 확인 후 삭제.
- 홈페이지 3파일은 교체 전 운영 파일이 수정 기준과 동일함을 확인 후 반영.

## 참고
- 테섭 파일 통째 복사 금지 원칙에 따라 본섭 hr·규칙은 독립 패치.
- 본섭에는 등록된 공고 0건으로 시작. 사람인 "공조설비 납품 PJT 팀원" 공고(마감 10/23)는 대표님이 포털에서 등록.
