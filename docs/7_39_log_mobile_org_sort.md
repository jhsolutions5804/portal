# 모바일 조직도 정렬 변경 (2026-09-19)

> 작성: 춘식이(Claude)

## 요청
대표님 — 모바일 환경 검토 시작. 조직도가 두서없이 나온다(부서 가나다순 + 부서 내 직급순)며 사번 순 정렬 요청 후, 세부 규칙 확정:
1. 송지훈은 부서 표시 없이 항상 맨 위
2. 부서 순서: 사업본부, 경영지원본부, 경영총무팀, 현장관리팀, 인력배치팀, guest, 미지정
3. 각 부서 안에서 사번 순

## 원인
`m/admin.html` `renderOrg()`가 `Object.keys(byDept).sort()`로 부서를 가나다순 정렬하고, 부서 내에서는 직급(`rankIdx`) 우선 → 사번은 보조 키로만 사용. 사번 기준 나열이 되지 않았음. (사번 없는 사용자는 `''` 비교로 맨 앞에 옴)

## 수정
`m/admin.html`
1. `ORG_DEPT_ORDER` 고정 순서 + `deptRank()` — 목록 외 부서는 `guest` 뒤·`미지정` 앞, `미지정`은 항상 마지막.
2. `isTop()` — 이름 `송지훈` 또는 직급 `대표` → 부서 그룹에서 분리해 헤더 없이 최상단 카드로 렌더. 부서 수 집계에서는 제외, 전체 인원에는 포함.
3. `cmpEmp()` — 사번 numeric 비교(숫자 사번 < 문자 섞인 사번), 사번 없음은 맨 뒤, 동률 시 직급 → 이름.
4. 카드 마크업을 `orgCard()`로 분리(동작 동일).
5. 버전 주석 추가: `build: 20260919a · ver: 2026-09-19 (모바일 관리 2.7.0)`.

`renderAdmin()`(Portal 관리)과 PC `loadOrg()`는 변경 없음.

## 검증
- `<script type="module">` 추출 → `node --check` 통과 (production/portal-test 두 파일)
- CSS 중괄호 깊이 0, 음수 구간 없음
- 실제 화면 인원 + 엣지케이스(사번 없음·숫자형 사번·목록 외 부서·현장관리팀 다인원) 시뮬레이션: `송지훈 → 김종화 → 김영희 → 김민서 → 현장관리팀(사번순, 사번없음 맨뒤) → 인력배치팀 → guest → (목록 외 부서) → 미지정(test)` 확인
- production ↔ portal-test 파일 diff = Firebase 설정 3줄만 다름, 설정 혼입 없음(`portal-test` 문자열이 production에 없음)

## 배포
대표님 지시("둘 다 해") 따라 production + portal-test `m/admin.html` 동시 배포. 각 레포 원본에 동일 패치를 독립 적용. 버전 → 모바일 관리 2.7.0, 백업 `backup/v2.7.0/m/admin.html`(양쪽).

## 참고
- 지정 부서 목록에 없는 부서(현재 PC `DEPT_ORDER`에 있는 영업기획팀 등)는 `guest` 뒤에 붙음. 지정 순서에 넣으려면 `ORG_DEPT_ORDER`에 추가.
- PC 조직도와 모바일 조직도의 부서 순서가 서로 다름(PC: 미지정 → 사업본부 → 현장관리팀 → 인력배치팀 → 경영지원본부 → 경영총무팀 → 영업기획팀).
