## 변경 (`pjt_roster/index.html`)
1. **주소 입력**(2.3.0): 인적사항에 주소 칸. 관리자 전용 `master_worker_private.address`에 저장.
2. **통장사본**(2.3.0→2.3.1): 사진 파일 칸이 아니라 관리자 전용 '급여/계좌' 구역(은행·계좌번호·일당 아래)에 첨부. 저장은 사진과 같은 `master_worker_photos`(슬롯 `bankbook`, 문서ID `<ID>__bank`), 목록 첨부 배지에서는 제외(`PHOTO_SLOTS`).
3. **주소 인사 연동**(2.4.0): 이름+생년월일이 같은 인사 근로자(`workers`+`worker_private`의 주민번호로 생년월일 계산)가 있으면 주소를 읽기 전용으로 표시하고 연명부에는 저장하지 않음(한 곳에서 관리). 외주·협력 인력은 직접 입력. 본섭 데이터 대조: 연명부 13명 중 인사 명단과 일치 4명(재직 3·퇴사 1), 나머지는 외주·협력.
4. **원청 하위 탭 + 법정교육**(2.5.0·2.5.1): 삼성전자=법정교육/자격·인증/사내화 교육·상생협력포탈(포탈 계정이 위), SK하이닉스=법정교육/자격·인증. 법정교육은 시공사·교육 종류·교육일·시간·비고를 입력하고 **시공사별로 따로** 교육 종류별 누계·올해·분기별 집계. 저장 위치 `master_worker_private.legalEdu`(규칙 변경 없음). 2.5.1은 전역 `table{min-width:980px}` 때문에 누계 표가 창 밖으로 나가던 문제 수정(실제 브라우저 840/520/360px 검증).
