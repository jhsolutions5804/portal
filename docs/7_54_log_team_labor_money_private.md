# 개발로그 — ⑤ 팀별 노무비(기획>정산) + 금액 데이터 관리자 전용 이동

> 작성: 춘식이(Claude) · 2026-09-30 · 배포: portal-test → **본섭 반영은 별도 세션에서 완료 (`7_56_log_prod_roster_batch.md`)**

## 요청 · 결정

- 연명부 재편 ⑤: 월간 공수의 팀별 합계(금액 포함)를 기획>정산으로 이전.
- 대표님 결정: 월간 공수는 관리자만 보는 것이 맞고, 직원(특히 여러 팀을 가진 경우 다른 팀의 단가)이 금액을 볼 필요가 없음 → **금액을 데이터 수준에서 관리자 전용으로** (설계안 1안).

## 정정 사항

- 이전에 “일당은 월간 공수(팀 단가 집계)가 `master_workers`에서 읽으므로 유지”라고 설명했으나 **오류**였음. 코드 확인 결과 팀별 금액은 팀장 문서의 `teamRate`로만 계산하며 개인 `dailyRate`는 월간 공수·연명부의 입력/수정 폼에서만 읽고 쓰일 뿐 어떤 계산에도 쓰이지 않음(전 모듈 전수 검색). 따라서 일당도 안전하게 이동 가능.

## 설계 메모

- 읽기 순서: 관리자 전용 문서 → 옛 위치. 그래서 **모듈 배포 → 데이터 이전** 순서라면 어느 시점에도 화면이 정상(월간 공수가 0원으로 보이는 구간 없음).
- 규칙 변경 없음: `master_worker_private`는 v1.0.0 배포 시 이미 관리자 전용.
- 기획은 관리자만 접근하므로 팀 단가 읽기·쓰기가 규칙과 충돌하지 않음.
- 기획에서도 마스터 미등록 인원(팀 없음)의 공수를 안내해 월간 공수 합계와 대조 가능.
