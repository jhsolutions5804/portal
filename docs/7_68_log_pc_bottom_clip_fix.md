# 7.68. 개발로그 — PJT관리 PC 화면 하단 잘림 수정 · 발주처/시공사/협력사 한 줄 배치

> 2026-09-30 · 춘식이(Claude) · 대표님 캡처 제보 · 테섭·본섭 동시 반영(UI 수정)

## 1. 하단 잘림 (프로젝트 종료 버튼)
- 증상: PJT관리(경량) 설정 화면에서 맨 아래 '프로젝트 종료' 버튼이 화면 아래에 걸려 끝까지 스크롤해도 잘림.
- 원인: PC 레이아웃(≥900px)에서 본문 `.app`에 기본 규칙 `min-height:100vh`가 그대로 남아, 상단 메뉴(52px)만큼 본문이 화면 밖으로 밀려나고 `body{overflow:hidden}`이라 맨 아래 52px가 닿지 않음.
- 수정: PC 규칙에 `min-height:0` 추가(`pjt_light` 3.8.1), `.content` 하단 여백 32px. 같은 CSS 패턴인 메인 PJT(`pjt`)에도 방지 적용. (SUP `pjt_ph4`는 종료된 프로젝트라 제외)
- 검증: 실제 CSS·DOM을 Chromium에서 1280×800에서 재현(수정 전 버튼 하단 813/800 잘림 → 수정 후 761 완전 표시), 1880×946·900×700에서도 확인.

## 2. 발주처·시공사·협력사 한 줄
- PJT관리 설정(`pjt_light`): 3개 입력을 한 줄 3칸(520px 이하 폰은 세로), 기본정보 조회 카드는 '발주처 / 시공사 / 협력사'를 한 줄에 표시.
- 기획 프로젝트 수정(`gihoek` 5.10.1): 동일하게 한 줄 3칸. 신규 클래스 `.pf-row3` 사용(기존 `.row3`와 충돌하여 폰 배치가 안 바뀌는 문제를 검증 중 발견해 분리).
