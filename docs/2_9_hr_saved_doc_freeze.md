# 2.9. 인사 — 저장 서류 양식 동결 (근로계약서·연봉계약서·급여명세서)

> 대상: `hr/index.html` v2.4.1 · 최초 작성: 2026-09-19 · 작성: 춘식이(Claude)
> 관련: `2_2_hr_labor_annual_r3.md`, `2_3_hr_annual_r2.md`, `2_5_hr_payslip_r3.md`, `7_42_log_hr_saved_doc_freeze.md`

---

## 원칙 (대표님 지시)

1. **직원이 서명하고 저장한 서류는 어떠한 경우에도 내용이 수정되면 안 된다.**
2. 시스템 변경(비포괄임금제 전환, 급여명세서 항목 변경)은 그대로 유지한다.
3. 변경 **이전에 작성된 서류는 작성 당시 모습 그대로** 조회·PDF 출력한다.

## 문제의 원인 (2026-09-19 분석)

저장 문서에는 **입력값만** 저장된다(시급·직군·계약일·서명 등). 계약서 본문·금액표는 저장되지 않고,
조회/PDF 출력 때마다 **현재 양식 + 현재 계산식(`calcAnnualSalary`)** 으로 다시 그렸다.
→ 8/29(비포괄 전환)·9/1(조항 보강)·9/2(wageType) 배포 때마다 기존 문서가 함께 바뀜.
예) 연봉계약서: 저장된 `salary`(고정연장 포함)와 새 계산식 월급여표(고정수당 0)가 어긋나 연봉≠합계×12로 출력.
급여명세서(9/2 이후 양식)도 조회 시 `psCalcAll()`이 화면 상태(`ps`)로 재계산해 기술수당·여비교통비·휴일근로수당이 저장값과 달라질 수 있었음.

## 양식 버전 (tplVer)

| ver | 적용 시각(운영 배포, KST) | 특징 |
|-----|--------------------------|------|
| `v0` | ~ 2026-08-29 16:47 | 포괄 양식 — 연봉계약서 고정연장/고정야간수당·제5~7조 요약, 급여명세서 고정수당 항목 |
| `v1` | 2026-08-29 16:47 ~ | 비포괄 전환 — 실근무 기반 연장/야간/휴일수당, 연봉계약서 비포괄 안내문구 |
| `v2` | 2026-09-01 11:33 ~ | 조항 보강 — 연봉 제2조의2·제5~7조, 근로 제4조 여비교통비·기술수당, 급여명세서 기술수당·여비교통비 행 |
| `v3` | 2026-09-02 17:20 ~ | 포괄/비포괄 선택(`wageType`), 여비교통비 다중 유형(`travelItems`) — **현재 양식** |

- 근로계약서는 본문 차이가 제4조 한 문장뿐이라 `v0=v1`, `v2=v3`(2벌).
- 판정 `docTplVer(d)`: ① 문서의 `tplVer` → ② 없으면 `savedAt`을 `DOC_TPL_ERAS` 경계와 비교 → ③ `savedAt`도 없으면 `v0`.
- **저장 시** 세 서류 모두 `tplVer: DOC_TPL_CURRENT('v3')` 기록(`annualSave2`·`laborSave2`·`psSave`).

## 구조 (hr/index.html, `⟦FROZEN-DOC-TEMPLATES⟧` 블록)

| 항목 | 설명 |
|------|------|
| `__annualHtml_v0~v3(f)` / `__laborHtml_v0·v2(f)` / `__psHtml_v0~v3(d)` | 시대별 **동결 렌더러**(HTML 문자열 반환). git 이력의 당시 코드를 기계적으로 변환 — **수정 금지** |
| `__calcAnnualSalary_v0 / _v1` | 동결 계산식(v0=포괄, v1~v3=비포괄). 현재 `calcAnnualSalary` 변경과 무관 |
| `__psSavedPs(d)` · `__psSavedC(d)` | 저장된 급여명세서 → 양식 입력 변환. **재계산 없이 저장값 그대로** (공제·지급계·실지급액 포함) |
| `docHtmlByVer(map, d)` · `__docOpenWin(html)` | 버전 판정 후 렌더 → 새 창 출력 |
| 진입점 | `annualPreviewSaved2(d)` · `laborPreviewSaved2(d)` · `psViewDetail(d,wid)` (조회 화면 📄 PDF 출력) |

작성 화면의 **미리보기**(`annualPreview2`·`laborPreview2`·`psPreview`)는 기존대로 현재 양식·현재 입력값 사용.
`annualPreviewSaved2`는 더 이상 전역 `annualForm2`를 덮어쓰지 않음(작성 폼 오염 방지).

## 양식·계산식을 바꿀 때 (필수 절차)

1. 기존 `__xxxHtml_vN` **수정 금지**. 새 버전(예 `v4`)을 추가.
2. `DOC_TPL_ERAS`에 `{ver:'v4', from:'배포시각'}` 추가, `DOC_TPL_CURRENT='v4'`, `__ANNUAL_TPL/__LABOR_TPL/__PS_TPL` 맵에 등록.
3. 계산식이 바뀌면 이전 계산식을 `__calcAnnualSalary_vN`으로 동결.
4. 이 문서의 버전 표 갱신.

## 검증 (2026-09-19)

- 시대별 원본 코드 출력 vs 동결 렌더러 출력 **32건 완전 일치**(연봉 v0~v3·직군·wageType, 근로 v0~v3, 급여명세서 v0~v3) + 버전 경계 초 단위 판정.
- 사례: 시급 10,320원 사무직 8/29 이전 연봉계약서 → 고정연장 538,085원 포함 합계 2,690,424원 ×12 = 계약연봉 32,285,088원 일치.

## 알려진 한계

- 계약서 (갑) 서명/도장 이미지는 현재 등록본(`company_settings`)을 표시(서류별 고정 안 함).
- 저장 급여명세서에는 입사일·생년월일이 저장돼 있지 않아 출력 시 `-` (기존 동일).
- 초과근로·퇴직금 계산은 문서가 아니라 계산이므로 현재 `calcAnnualSalary` 사용.
- 8/29 이전에도 더 오래된 양식 변경(6~7월)이 있었으나 `v0`는 8/29 직전 양식을 기준으로 함.
