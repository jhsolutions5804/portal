# 0.7. 포털 공용 — 시간 입력 24시간 통일 (`time24.js`)

> 최종 개정: 2026-10-01 · 춘식이(Claude) · 대표님: "시간 입력하는 모든 툴을 오전/오후 12시간제 말고 24시간 포맷으로"

## 원리
`<input type="time">`의 표시 형식(오전/오후)은 사용자 브라우저·기기 설정이 정해서 코드로 24시간제를 강제할 수 없다. 그래서 공용 파일 `time24.js`가 모든 `input[type="time"]`을 24시간(HH:MM) **텍스트 입력 칸**으로 자동 변환한다(페이지 로드 시점 + 이후 동적으로 추가되는 칸까지 MutationObserver로 처리).

## 동작
- 숫자만 쳐도 자동 서식: `7`→07:00, `730`→07:30, `0700`→07:00, `20:0`→20:00. 숫자 키패드(inputmode=numeric), 포커스 시 30분 단위 제안 목록(datalist).
- 범위 밖 값(25:00 등)은 입력 단계에서 막거나 직전 값으로 복귀. 삭제(백스페이스)는 콜론에 막히지 않음.
- `.value`는 항상 `HH:MM` 문자열 → 기존 저장·계산 코드는 수정 불필요. `change` 이벤트를 캡처 단계에서 먼저 정규화하므로 기존 `onchange`도 정규화된 값을 읽음.
- 비워 두기 허용(빈 값).

## 새 화면에 쓰는 법
`<head>` 첫머리에 `<script src="(상대경로)time24.js?v=20261001"></script>` 한 줄만 넣고, 시간 칸은 평소처럼 `<input type="time">`로 쓰면 된다. CSS에서 `input[type="time"]`로 꾸미는 경우 `input.t24`도 함께 지정(변환된 칸에 `t24` 클래스가 붙음).

## 적용 화면(본섭 7)
포털 홈(index.html) · 인사(hr) · 전자결재(edoc) · 업무일지(daily-report) · 모바일 전자결재(m/edoc) · 모바일 PJT(m/pjt) · 모바일 일정(m/schedule). 테섭에는 출퇴근 기록(attendance)도 적용(본섭엔 해당 모듈 없음).

## 예외·참고
- 채용 지원자의 **면접 일시**는 datetime-local(오전/오후 고정) 대신 `날짜 + 24시간 시간` 두 칸으로 교체. 두 칸이 모두 입력돼야 `YYYY-MM-DDTHH:MM`으로 저장(기존 값 형식 그대로)되고 인사 캘린더에 등록, 날짜를 지우면 일정 해제.
- 기기 기본 시간 휠(돌려서 고르는 방식)은 없어지고 직접 입력/목록 선택 방식이 된다. 불편하면 시·분 선택 목록 방식으로 교체 가능.
- 홈페이지(jhsolutions5804.github.io)에는 적용하지 않음(시간 입력 칸 없음).
