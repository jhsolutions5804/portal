# 7.62. 개발로그 — 저장 계약서 메일 재전송 + 발송 이력 (인사 2.16.0)

> 2026-09-30 · 춘식이(Claude) · 대기열 2번 · **portal-test 배포, 본섭 미반영(대표님 확인 대기)**

## 요구
- 작성 완료된 서류를 포털에서 다시 메일로 전송.

## 구현
- 저장된 근로/연봉계약서 조회 화면 각 카드에 **📧 메일 재전송** 버튼 + **발송 이력 줄**(최근 발송 시각·마스킹 주소·총 횟수).
- 재전송은 1번의 **열람 전용 링크(180일)**를 새로 만들어 EmailJS로 발송(기존 `sendDocLinkByEmail` 재사용 → 이메일 확인/프롬프트, 등록 주소 자동 사용).
- 이력은 별도 컬렉션 `doc_send_log`에 기록(저장 서류 원본에는 쓰지 않음 — 양식·내용 동결 원칙, 서명 반영 해시 보호). 주소는 마스킹(ab***@도메인)만 저장, 링크 토큰은 저장하지 않음(전 직원 열람 가능한 컬렉션이므로).
- 기존 신규 작성 화면의 '📧 이메일 발송'(서명 요청)은 그대로.

## 검증
- Node vm + 모의 Firestore/EmailJS: 열람 링크(status=view) 생성, 메일 파라미터(to_email/to_name/doc_label/company_name/link), 이력 기록(마스킹), 목록 이력 줄 표시, 이메일 없음+취소 시 미발송.
- 실제 메일 수신·화면 확인은 대표님 테스트 필요.
