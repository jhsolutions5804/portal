# 7.76. 개발로그 — 모바일 메뉴 구조를 PC와 동일하게 (연명부는 PJT 관리 하위)

> 2026-09-30 · 춘식이(Claude) · 배포: **테섭** (본섭 미반영)

## 지적 (대표님)
“왜 연명부가 홈에 있어 — PJT 관리에 있어야지. Structure를 PC와 동일하게 짜야하지 않겠니?”
→ 맞는 지적. 직전 작업에서 모바일 홈에 연명부 카드를 얹어 PC 구조와 어긋나게 만들었음(PC는 PJT 관리 ▾ 하위).

## 원칙
**PC 포털의 메뉴 트리를 기준(source of truth)으로 모바일을 맞춘다.** 같은 화면 파일을 재사용하는 항목은 파일을 공유해 기능이 항상 일치.

## PC ↔ 모바일 구조 대조 (변경 후)
| 위치 | PC 사이드바 | 모바일 |
|------|-------------|--------|
| 업무 | 기획 / 인사 / 전자결재 / PJT 관리 ▾ / 내 팀 공수표 | 홈 업무 메뉴가 **같은 순서** (이전: 기획·인사가 “더보기” 작은 아이콘) |
| 아래 묶음 | 조직도 / 내규 열람 / Portal 관리 | 홈 “더보기”: 조직도 / 내규 / Portal 관리 |
| PJT 관리 하위 | PJT 홈 / 회사 일정 / **근로자 연명부** / 종료 PJT | PJT 관리: 진행 프로젝트 + **PJT 메뉴(회사 일정 / 근로자 연명부(관리자) / 종료 PJT)** — 종료 PJT는 신설(PC와 같은 데이터: 종료된 고정+경량 PJT) |
| 기획 > 정산 | [정산서] [팀별 노무비] | 정산에 **[정산서][팀별 노무비]** 전환(관리자) — 팀별 노무비는 공용 팀 화면(단가 설정 포함) |
| 내 팀 공수표 | 업무 모듈(팀장·관리자) | 홈 업무 메뉴(팀장·관리자) |

## 변경
| 파일 | 내용 |
|------|------|
| `m/home.html` | 업무 메뉴를 PC 순서로 재구성, 더보기를 PC 하단 묶음으로, **연명부 카드 제거** |
| `m/pjt.html` v5.4.0 | PJT 메뉴(회사 일정·연명부·종료 PJT), 종료된 경량 PJT를 `endedLight`로 보관, `renderEnded()`, `openEnded()` |
| `m/gihoek.html` | 정산 [정산서][팀별 노무비] 전환(관리자) |
| `pjt_roster` v1.8.1, `team` v1.3.1 | `back` 파라미터로 진입한 모바일 화면으로 복귀(허용 목록 `home/pjt/gihoek/hr/edoc/admin.html`만, 그 외·외부 주소는 홈) |

## 시험 중 발견·수정
- 종료 PJT 진입에서 `nav is not defined` — `nav`가 모듈 내부 함수라 HTML `onclick`에서 호출 불가. `window.openEnded`로 노출(제가 새로 넣은 진입 코드의 결함, 실제 브라우저 클릭 시험에서 발견).
- 시험 자체 오류 2건(홈에 ‘연명부’ 글자가 하나도 없어야 한다는 과도한 검사식 — PJT 관리 카드 설명문에는 의도적으로 언급, 함수 추출 방식) 정정. 연명부 시험 1건은 문구 변경(← 홈 → ← 뒤로)에 맞춰 갱신.

## 검증
- 구조 시험 15(홈 순서·하단 묶음·연명부 위치·PJT 하위 순서·정산 전환·back 허용 목록: 악의적 주소 `https://evil.example`·`//evil.example`·`../index.html`도 홈으로), 연명부 168, 팀 화면 46, 진입점 18.
- 실제 브라우저(모바일 390px): 홈(관리자·팀장·일반 직원별 메뉴), PJT 관리(관리자·일반 직원), 종료 PJT 화면·뒤로 가기.

## 배포 (테섭)
5개 파일. 원본이 기준본과 동일함 확인 후 배포, 백업 `backup/20260930_structure/before|after/`. (배포 명령이 서빙 확인 단계에서 시간 제한으로 중단되었으나 배포·백업은 5개 모두 완료되어 있음을 저장소 대조로 확인 후 빌드·서빙만 재확인)

## 남은 차이
- 모바일 Portal 관리는 조회 전용(계정 생성·사번/직급 수정·권한 칩 없음).
- PC 기획·인사·전자결재의 하위 메뉴(예: 인사의 근로자 명부·근로계약서 등)와 모바일 각 화면의 항목이 1:1로 같은지는 대조 필요(기획은 프로젝트·거래처·견적·정산·회계 5개 일치 확인).
