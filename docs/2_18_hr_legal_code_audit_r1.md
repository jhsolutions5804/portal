## 2. 항목별 상세

### 2-1. 연봉 산식 (🟢 문서 정정)
- 코드: `basic = 시급×8×5×4.345`, `weekly = 시급×8×4.345`, `fixedOt = fixedNight = 0` ("포괄임금제 폐지" 주석).
- 따라서 `2_2_hr_labor_annual_r3.md`의 현장직 `fixedNight`, 사무직 `fixedOt` 산식 설명은 **구버전** → 2.2 개정 시 삭제.
- 2_14에서 제기한 "양식·계산식 불일치"는 **기본(비포괄) 경로에서는 불일치 없음**으로 해소. 단 아래 2-2 포괄 옵션이 남아 있음.

### 2-2. 포괄임금 옵션 (🔴)
- 현장: 매월 실제 근무기록으로 연장·야간 산정 가능 → 포괄임금 유효성 인정이 어려운 구조. 정책 기본값은 **비포괄 유지**.
- 현 양식 문제: ① "근로자 본인의 선택" 문구는 효력 보강이 되지 않음 ② 고정연장·야간 **시간수와 산정식 미기재** ③ 실제 초과분 **차액 지급 문구 없음**.
- 정책안: **포괄 선택을 신규 계약에서 차단**(또는 경고 후 노무사 확인 전 사용 금지). 기존 포괄 계약자가 있으면 목록 점검 후 차액 정산 여부 검토 🔶.

### 2-3. "소정근로시간(주52시간)" 문구 (🔴)
- 소정근로시간은 당사자가 정한 근로시간(법정 주 40시간 이내)이며 연장 포함 상한 52시간과 다름.
- 수정 문안: **"위 임금구성은 소정근로시간 주 40시간(월 209시간) 기준으로 작성됨. 연장·야간·휴일근로는 별도 산정·지급."**
- 영향 양식: 연봉계약서 제2조 하단 주석(최신 양식 및 구 tplVer들). 근로계약서 제6조는 이미 "주 40시간"이라 정상.
- 저장 서류는 동결되므로 **신규 tplVer로 수정**, 기존 체결분은 변경 합의서(2_17 §2-③)로 정리.

### 2-4. 통상시급·퇴직금·4대보험·최저임금 (🔴🟠)
- **통상시급 산식(2_14 확정)** `= (기본근로수당+주휴수당+정기·일률수당) ÷ 209`을 `psCalcAll`(연장·야간·휴일)과 `retireCompute` 비교 로직에 적용. 기술수당 포함, 여비교통비는 항목별 스위치.
- **퇴직금 평균임금**: 3개월 임금 총액에 휴일근로수당·기술수당·연차수당 포함, 상여금·연차수당은 **연 지급분의 3/12 가산** 방식으로 정비 🔶. 평균임금 기간은 달력월 근사이므로 실제 퇴직일 기준 3개월 일수 산정 방식 확인.
- **4대보험**: 요율을 연도별 테이블로 분리(2026: 4.75% / 3.595% / 건강보험료×13.14% / 0.9%), 국민연금 기준소득월액 상·하한 적용. 급여 공제는 **공단 고지액 기준이 원칙**이므로 시스템값은 추정치이며 고지액과 차이 정산 필요 🔶. 2027년 요율은 확정 후 갱신.
- **최저임금**: 계약 저장 시·월 급여 계산 시 시급 비교 경고(2_17 §2-①). 연도별 상수 테이블(2026 10,320 / 2027 10,700).

### 2-5. 연장근로 판정 방식 (🟠 🔶)
- 현 방식: 월 실근무시간 − 월 소정근로시간(평일수×8h) 초과분 = 연장.
- 법정 연장은 일 8h·주 40h 초과. 일 8h 초과 근무와 다른 날 단축이 상쇄되면 월 합산에서는 연장이 줄어들 수 있어 **근로자 불리 가능성**. 안전측 정책: 일·주 단위 초과분을 별도 계산해 **더 큰 값을 적용**. 구현 범위는 노무사 확인 후 결정.

### 2-6. 연차 (🟠 🔶)
- 회계연도 운영은 입사일 기준보다 불리하면 안 됨. 현 로직(입사 첫해 비례 15일 + 첫 1년 월 개근분 최대 11일)의 합계가 입사일 기준 산정 이상인지 **샘플 근로자 몇 명으로 대조** 필요.
- 퇴직 시 입사일 기준 재산정·정산 로직의 존재 여부 확인 필요.
- 2027.6.10 시행 연차 분할(반일·연 5일 한도 예고안): 반차 0.5일 처리는 이미 지원. 시간 단위 도입 시 잔여 계산 개편.
- 연차사용촉진(`renderLeavePromoMain`): 1년 이상은 6개월 전 10일 이내 + 2개월 전까지, 1년 미만은 3개월 전 10일 이내 + 1개월 전까지 시기가 코드와 일치하는지 점검.

### 2-7. 신규 필요 기능 (🟠)
- 4시간 근무 휴게 미부여 신청: 2_17 §2-⑤ 기준. **2026.12.10 전**.
