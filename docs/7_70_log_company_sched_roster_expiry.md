# 7.70. 개발로그 — 연차 회사 일정 분리 · 연명부 만료일 자동 계산 · 만료 일정 자동 생성

> 2026-09-30 · 춘식이(Claude) · 화면 코드 본섭 반영 완료, **서버 함수 재배포·데이터 이전은 대표님 재배포 후 진행**

## 요구(대표님)
- 연차는 특정 PJT에 속하지 않게(전 직원 조회), PJT 외 일정도 등록.
- 연명부의 검진·자격·교육 만료일을 자동 연동하되 수정 가능, 직원이 조회 가능(공용 캘린더). 검진 유효기간: 일반·배치전 각 1년.
- 원본 연차 정리: 복사 후 삭제(삭제는 관리자가 화면에서 직접 실행).
- 후속(순차): ③ 검진 결과 PDF 첨부(Firebase Storage 시작 필요) ④ 인사 캘린더(면접·연봉제안 회신·연봉협상·인사평가, 관리자+김민서).

## 반영(화면 코드, 본섭)
- 결재 4.10.0: 연차 게시 → `company_schedules/leave_<결재문서ID>`(고정 ID로 중복 방지)에 등록. 기존에는 P4 Ph2 일정(`user_schedules`)에 들어갔음.
- 연명부 1.6.0: 검진 만료일 = 실시일 + 1년(수동 수정 시 '수정됨', ↺로 자동 복귀) / 자격·인증 유효기간(1·2·3·5년) 선택 시 취득일 기준 만료일 자동(수동 수정 가능) / 목록에 D-day 배지·만료일.
- 포털 홈: 회사 일정 카테고리 행사·기타·만료 추가. (기존 일정 등록 창의 '회사 일정' 선택지 사용)
- `admin_cleanup_leave.html`(일회성 관리자 도구): 회사 일정에 복사본이 확인된 옛 연차(user_schedules, tag=off, [연차])만 조회·삭제.
- 적용 방식: 테섭에서 만든 변경분을 **현재 본섭 파일에 패치로 적용**(다른 세션의 본섭 수정 보존 확인 — 예: 모바일 전환 버튼 복구).

## 서버 함수(outlook-sync, 재배포 필요)
- `syncCompanySchedule`: company_schedules → 공용 캘린더. 연차 `[연차] …`(현장명 접두 없음), 회사 행사 `[회사] [구분] …`.
- `syncRosterExpiry`: master_worker_private 변경 → 검진(종류별 최신 실시일 +1년, 수동 만료일 우선)·자격·교육 만료를 `company_schedules/expiry_<근로자>_<종류>_<번호>`로 생성/갱신/삭제(퇴사자 제외, 결과·PDF 미포함).
- 테스트: 단위 17 + 트리거 통합(연차·행사·만료 생성/삭제 포함) 통과.
