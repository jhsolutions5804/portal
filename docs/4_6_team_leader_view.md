# 4.6. 내 팀 공수표 (팀장 전용)

> `portal/team/index.html` · 최초 작성 2026-09-30 · 작성 춘식이(Claude) · 적용 환경: **portal-test 배포 완료 / 본섭 미반영**

## 목적
팀장이 로그인해서 **자기 팀**(본인 + 팀원)의 월별 공수, 개인별 공수표, **팀 단가·노무비**를 조회한다. 팀원·일반 직원·관리자(팀장 지정 없음)는 대상이 아니다(관리자는 연명부 > 월간 공수, 기획 > 정산 > 팀별 노무비 이용).

## 구조
| 구성 | 내용 |
|------|------|
| 팀장 지정 | 관리자가 **연명부 > 팀장 수정 > “팀장 포털 계정”** 에서 포털 계정을 선택 → `portal_users/{uid}.teamLeaderIds`(배열)에 팀장 ID 추가/제거. 한 계정에 팀 여러 개 연결 가능. 목록의 팀장 행에 `🔗 계정명` 표시. |
| 계정 문서 | `teamLeaderIds`는 관리자만 쓸 수 있음(직원 본인은 phone·phoneVerified·phoneVerifiedAt만 수정 가능 — `7_71`, `7_72`). |
| 팀 단가 | 기획 > 정산 > 팀별 노무비에서 저장 시 **두 곳**에 기록: `master_worker_private/{팀장ID}.teamRate`(관리자 전용) + `team_rates/{팀장ID}.teamRate`(관리자 + 그 팀 팀장만 조회). |
| 규칙 | `team_rates/{id}`: 읽기 = 관리자 또는 (승인 계정 && `id in portal_users/{uid}.teamLeaderIds`), 쓰기 = 관리자. 컬렉션 목록 조회는 관리자만. 포괄 규칙에서 제외. 에뮬레이터 검증(다른 팀 차단·여러 팀·미승인·외부 도메인 등). |
| 진입점 | 포털: MODULES `myteam`(`jhModAllowed` — 팀장 지정 계정에만 카드·사이드바 표시, 권한 칩 대상 아님, `openModule` 가드) / 모바일 홈: `내 팀 공수표` 카드(`jh_login_perms.teamLeaderIds`) → `../team/index.html?via=mobile` |

## 화면
- 상단: 월 이동(‹ ›), 접근 조건 안내(비로그인·미승인·팀장 아님·관리자).
- 팀별 카드: 팀 공수 · 팀 단가 · 노무비, 프로젝트별 소계 칩(공수·금액), 본인+팀원 행(공수·프로젝트별 공수·퇴사 표시)과 `📋 공수표`.
- 개인별 공수표: 일자별 달력 + 프로젝트별 공수 + 월 합계, `PNG로 저장`(`이름_YYYYMM_공수표.png`).
- 단가 문서가 없으면 “미설정”, 조회 권한 오류면 “조회 불가”(공수는 표시). 지정된 팀장 문서가 없으면 안내.
- 집계 방식은 연명부 월간 공수·기획 팀별 노무비와 동일(이름+생년월일 키, 범위 조회, 종료 PJT 제외, 연속 월 이동 시 마지막 결과만 반영).

## 보안 한계
- 자기 팀만 보이게 하는 것은 **화면 수준**(공수 원본 컬렉션은 승인 직원이 읽을 수 있음). **금액(팀 단가)은 규칙 수준**에서 자기 팀만 조회 가능. 개인정보·주민번호 등은 관리자 전용 문서라 접근 불가.

## 검증
팀 화면 25항목, 연명부 159(기존 143 + 연결 16), 기획 팀별 노무비 30(이중 저장·부분 실패 포함), 진입점 17(접근 판정·회귀·모바일 카드), 규칙 14 + 계정 문서 시나리오, 단가 복사 스크립트(에뮬레이터).
