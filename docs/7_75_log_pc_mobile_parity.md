## 1. 관리자 내 팀 공수표 — 진단
- **실제 보안규칙·로그인이 있는 환경(에뮬레이터 + 실제 Chromium)** 에서 배포본으로 재현: 팀 화면(관리자·팀장·일반 직원), PC 포털 홈/사이드바, 모바일 홈(로그인 후 `jh_login_perms` 흐름 포함) **모두 관리자에게 정상 표시**. 코드 결함 없음.
- 추정 원인: 휴대폰 브라우저에 **직전 버전 화면(m/home.html)이 캐시**되어 예전 조건(팀장 지정 계정에만 표시)이 적용됨(관리자 표시를 올린 직후 테스트 계정의 팀 연결도 해제했으므로 카드가 사라짐).
- 조치(재발 방지): 포털이 모바일 홈으로 이동할 때 `?v=<빌드>` 부여, 모바일 홈은 주소의 `v=`와 자기 빌드가 다르면 세션당 1회 새로 받기.
- 진단 중 시험 환경 오류(계정 uid 어긋남, 에뮬레이터 프로젝트 ID 불일치, 연결 코드 삽입 위치) 발견·수정 — 코드와 무관.

| 항목 | 이전 | 변경 |

| 근로자 연명부 | 모바일 없음(PC 표를 억지로 축소해 이름이 글자 단위로 꺾임) | **같은 파일 v1.8.0**: 좁은 화면(≤700px)에서 목록을 카드로(표와 같은 사람·정보·버튼, 시험으로 일치 확인), 머리글·버튼 꺾임 방지, 폼 전체 화면·16px 입력(확대 방지). 모바일 홈에 관리자 전용 카드, `?via=mobile` 단독 진입 시 ← 홈 |
| 팀 단가 설정 | PC 기획 > 정산 > 팀별 노무비 ✏️만 | **내 팀 공수표(관리자) 각 팀 카드 ✏️** 추가 — 기획과 같은 두 문서(`master_worker_private` + `team_rates`)에 저장, PC·모바일 공통 |

| 팀장 계정 연결 | PC 연명부 | PC 연명부 + 모바일 관리(이전 작업) |
