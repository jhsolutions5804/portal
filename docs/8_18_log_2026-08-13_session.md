## 후속 — 진짜 원인 재수정 (같은 세션)

대표님 재확인 결과 여전히 저장 안 됨. 콘솔 로그 확보 후 재분석.

**진짜 원인**: `fmtTel`/`fmtTelBlur`가 `<script type="module">` 내부 일반 함수로 선언되어 인라인 이벤트 핸들러(`oninput`/`onblur`, 전역 스코프 실행)에서 `ReferenceError`. 앞선 r2 수정은 애초에 도달 불가능한 코드였음.

**수정**: `window.fmtTel=fmtTel`, `window.fmtTelBlur=fmtTelBlur` 전역 노출 추가. 전체 인라인 핸들러 함수 전수 조사로 동일 문제 없음 확인(zoneGuess는 false positive).

**배포**: `gihoek/index.html`, `index.html`(버전배너, gihoek 5.3.7, build 20260813b), 백업 `backup/v5.3.8/gihoek/index.html`

## 후속 (2) — 견적/정산 인쇄 담당자 전화번호 오표시 수정

**증상**: 견적서에서 담당자 "배민철"을 선택했는데, 인쇄/PDF 출력물엔 다른 담당자("이경택")의 전화번호가 나옴.

**원인**: 인쇄 템플릿(`printEst`, `settleDocHTML`)의 공급받는자/수신 카드가 견적별로 선택한 담당자 스냅샷(`contact`/`contactTel`)을 쓰지 않고, 거래처의 레거시 회사 단위 `tel` 필드를 그대로 출력하고 있었음.

**수정**: 담당자가 선택된 경우 해당 담당자 이름+전화번호를 우선 표시하도록 견적서·정산서 인쇄 템플릿 모두 수정.

**배포**: `gihoek/index.html`, `index.html`(버전배너, gihoek 5.3.8, build 20260813c), 백업 `backup/v5.3.9/gihoek/index.html`
