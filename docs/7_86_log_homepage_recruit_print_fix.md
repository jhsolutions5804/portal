# 7.86. 개발로그 — 홈페이지 채용 지원 폼: 제출 후 이력서 인쇄 수정

> 2026-10-01 · 춘식이(Claude) · 대표님: "(이력서 인쇄 눌렀는데) 왜 이런 화면이 나오나?" → 수정·테섭 시험·본섭 반영
> 대상: 홈페이지 저장소 `jhsolutions5804/jhsolutions5804.github.io` 의 `recruit.html` (포털 저장소 아님)

## 증상·원인
- 지원서를 제출한 뒤 "이력서 인쇄 / PDF 저장"을 누르면 이력서 대신 "지원서가 접수되었습니다" 안내 화면이 인쇄됨.
- 제출 성공 시 코드가 입력 폼(`#recruitForm`)을 `hidden`으로 숨기는데, 인쇄할 이력서 미리보기(`#resumePreview`)가 그 폼 안에 있어 숨겨진 채로 인쇄에서 빠짐. 폼 제작 때부터 있던 문제(규칙 때문에 지원서 저장 자체가 안 돼 발견되지 않았음).

## 수정
- 성공 화면에 인쇄 전용 영역 `#printResume` 신설. 제출 성공 시 `renderResumePreview()`로 제출 내용을 다시 그려 제목("입 사 지 원 서")·지원 공고·제출일과 함께 복사.
- `@media print`: 접수 안내(아이콘·제목·문구·버튼)를 숨기고 `#printResume`만 출력. `print-color-adjust: exact`로 인쇄 설정에서 '배경 그래픽'이 꺼져 있어도 파란 제목줄(흰 글자) 유지.
- 제출·저장 동작은 변경 없음(저장 이후 단계에만 `try/catch`로 감싼 추가 코드).

## 검증
- 실제 브라우저(Chromium, 인쇄 미디어 에뮬레이션)로 재현(수정 전: 접수 안내만 인쇄) → 수정 후 이력서 표 인쇄 확인. Firebase는 가짜로 대체해 실데이터 저장 없음.
- 테섭 사본(`portal-test/recruit.html`, 테스트 서버 띠·테섭 Firebase 설정)을 대표님이 테섭 DB로 실제 제출·인쇄해 정상 확인 → 홈페이지(본섭) 반영.
- 본섭 반영 후 라이브 파일을 내려받아 같은 브라우저 시험 재통과. 라이브 파일에 테섭 설정·테스트 서버 띠 혼입 없음.
