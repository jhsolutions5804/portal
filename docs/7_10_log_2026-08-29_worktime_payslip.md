## 핵심 버그 및 원인

### 타임존 버그 (가장 큰 영향)
`cur.toISOString().slice(0,10)`로 날짜 문자열을 만들면 KST(+9) 브라우저에서 로컬 자정이 UTC로는 전날 15시라 **모든 날짜가 하루씩 밀림**. 총 근무일수 "합계"는 8/17(공휴일)이 잘못 포함되고 8/18(평일)이 잘못 제외되며 우연히 상쇄되어 정상으로 보였지만, 개별 날짜 하나하나는 다 밀려있어 실제 출근기록(로컬 날짜 저장)과 비교 시 전혀 매칭이 안 됨 → 완전개근인데도 주휴수당 0원. 수정: `getFullYear()+'-'+getMonth()+'-'+getDate()`로 로컬 날짜 직접 조합.

### PC 급여명세서 근태연동 누락
`renderPayslipWriteForm`(모바일)와 `renderPayslipPCRight`(PC)가 완전히 별도 함수인데, 근태 데이터 연동(`psFetchAttendanceData` 호출)을 모바일 쪽(`psWorkerSelect`)에만 추가하고 PC 쪽(`psPcWorkerSelect`)에는 빠뜨림 → PC 화면에서 "이번 달 0시간 근무"로 오인해 기본급이 160h 전체 부족분으로 대폭 삭감되고, 주휴수당은 출퇴근기록 없음 판정으로 옛 고정값(시급×8×4.345) 폴백.

### 업무일지 권한 오류
`renderDailyList`가 다른 문서함과 달리 `edoc_daily`를 무필터 전체조회 → Firestore는 규칙 불일치 문서가 하나라도 있으면 list 쿼리 전체를 거부 → 사원 계정에서 매번 에러. 표준 `fetchEdocDocs()`(authorUid/viewerUids/posted/관리자 분리쿼리)로 교체, 저장 시 `viewerUids` 필드 추가.

## 검증 방식
모든 계산 로직(근로시간 임계값, 야간시간, 휴일수당, 주휴 개근판정, 유급휴가 환산 등)을 jsdom/vm으로 mock Firestore 응답을 넣어 실제 함수를 실행하며 검증. 브라우저 없이도 계산 정확성을 코드 레벨에서 확인.
