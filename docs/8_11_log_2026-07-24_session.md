# 8.11. 세션로그 — 2026-07-24 PJT 5.0.0 세션

> 작성: 춘식이(Claude)

---

## 세션 흐름 요약

1. **신규 PJT 카드/사이드바 자동편입** 요청 → 절충안(경량 워크스페이스 템플릿 하나를 여러 PJT가 공유) 확정 후 진행
2. 경량 워크스페이스 v1(모바일 카드형) 제작 → "너무 모바일 같다" 피드백 → v2(품목체크+근태그리드) → "PC 대시보드가 아니다" 피드백 → v3(FAB 동일 PC 레이아웃)까지 3차 개선
3. 일정관리를 FAB 스타일 캘린더로 전면 개편, PJT 홈 통합캘린더와 연동
4. 사용 중 버그 리포트 다수 대응:
   - 캘린더 클릭 시 레이아웃이 밀리는 버그 (빈 셀 누적) → 수정
   - 공수 저장이 출역체크에 의존하던 버그 → 수정
   - 생년월일 입력창 폭이 좁던 문제 → 수정
5. **"월간 공수" 신규 메뉴** 요청 → 진행 중 **portal-test의 FAB/SUP가 프로덕션 Firebase를 그대로 쓰고 있던 위험 발견** → 긴급 분리
6. 월간 공수 집계 로직 구현 → SUP 공수가 안 잡히는 버그 다회 리포트
   - 1차: PJT별 합계가 0이면 행 자체가 안 보이던 UX 문제로 오판 → 수정
   - 2차: 근태화면 WORKERS 캐시 미갱신 의심 → 부분 수정하되 근본원인 아니었음
   - 3차: **SUP가 FAB와 다른 컬렉션(`ph4_manday`)을 쓴다는 사실을 디버그 패널로 최종 확인** → 집계 로직 근본 수정으로 해결
7. **근로자 마스터 명부 + 팀 구조 + 마이그레이션 도구** 신규 설계·구현 (이름+생년월일 고유식별, 팀장/팀원 1단계, 일당 관리자전용)
8. 마이그레이션 후 SUP 탭 새로고침 누락으로 재발한 것처럼 보였던 이슈 → 원인 설명 후 해결 확인
9. 마스터 명부 수정/삭제, 개인별 통합 공수표(캘린더+PNG저장) 추가
10. 사이드바 "월간 공수" 항상 최하단 고정 처리
11. **portal-test에서 최종 검증 완료 → 프로덕션(portal) 전체 반영**, 디버그 뱃지 제거 확인 후 배포
