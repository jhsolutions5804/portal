# 8.24. 세션로그 — 2026-08-29

## 세션 개요
근로시간 관리 시스템을 처음부터 구축(출퇴근 기록 → 근로시간 자동계산 → 급여명세서 자동연동)하고, 연차·기획-PJT관리 연동까지 함께 개편한 대규모 세션. 테섭(portal-test)에서 전 과정을 검증한 뒤 본섭(production) 배포까지 완료.

## 주요 작업 (시간순)

1. 업무일지 출퇴근시간 입력 추가 (10분 단위)
2. 출퇴근 기록 신규 모듈 → edoc 내부 탭으로 통합 (별도 페이지 시 포털 프레임 이탈 버그 발견 후 재설계)
3. 인사 "초과근로" → "근로시간" 메뉴 개편, 월 소정근로시간/최대초과근로시간 자동계산(캘린더 기준)
4. 연차신청서 캘린더+정보+리스트 레이아웃 개편, 전 직원 공개, 법정 휴가종류 정비
5. 유급휴가 → 근무시간 자동 반영
6. **급여명세서 전면 개편**: 포괄임금제 폐지, 기본/연장/야간/휴일/주휴수당 실근무기록 기반 자동계산 — 사용자와 여러 차례 근로기준법 조문(주휴수당·야간근로수당·휴일근로수당·연장근로 가산율) 확인하며 설계
7. 급여명세서 테스트 데이터 시딩 유틸리티 제작 (5명, 다양한 시나리오) — Firestore 직접 쓰기 권한이 없어 관리자가 브라우저에서 실행하는 일회성 페이지로 구현
8. **타임존 버그 발견 및 수정**: 사용자가 "윤석원 주휴수당이 왜 0원이냐"고 물어본 것을 계기로 발견. `toISOString()` UTC 변환 문제, 3개 파일 4곳 수정
9. **PC 급여명세서 근태연동 누락 버그 발견 및 수정**: 사용자가 스크린샷으로 기본급 오류값을 지적하면서 발견
10. 인사-근로시간 탭을 표에서 캘린더로 전환, 결근/연차/휴일근무 색상 구분, 관리자 CRUD, 업무일지 팝업 연동
11. 인쇄용 급여명세서 UI 정리 (줄바꿈 문제, 산출식 문구 갱신)
12. 기획-PJT관리 자동연동 설계 및 구현 — 연동 방향(기획→PJT관리) 논의 후 결정

## 배포
- 테섭에서 전체 기능 반복 검증 (다수의 재배포 사이클)
- 본섭 배포: `backup/v5.4.0/`에 5개 파일 백업 후 `daily-report`, `hr`, `edoc`, `gihoek`, `index.html(포털홈)` 순차 배포, 빌드 확인, Contents API로 반영 재검증

## 남은 작업 (다음 세션)
- 기존 어긋난 기획↔PJT관리 데이터(H17L↔화성17L, M15X) — 대표님이 화면에서 직접 재연결 필요
- 경량 PJT(`reg_*`)의 공정률·공수 자동정산 심화 연동은 미구현 (현재는 "연결"만 됨)
- 결재자(김종화·송지훈)가 관리자 계정이 아닐 경우 사원 업무일지 열람 제한 이슈 — 확인 대기 중
