# 8.17. 세션로그 — 전자결재 fetchEdocDocs 스코프 버그 수정 (2026-08-05)

## 요청
대표님(스크린샷 첨부): 연차신청서·지출결의서 페이지에서 `오류: fetchEdocDocs is not defined` 발생, 전자결재 페이지 로드 안 되는 문제 제보.

## 조사
- `edoc/index.html` 전체에서 `fetchEdocDocs` 정의·호출 위치 검색
- `renderEdocHome()`(862~1062줄) 함수 내부에 `fetchEdocDocs`가 중첩 선언(915줄)되어 있음을 확인
- 홈 화면 내 호출(952줄)은 같은 스코프라 정상, `renderDocList()`(1789줄, 연차·지출결의서 등 목록 렌더링), `loadApproveData()`(1106줄, 결재함)는 별도 최상위 함수라 접근 불가 → ReferenceError

## 변경 내용
- `fetchEdocDocs()` 함수를 `renderEdocHome()` 밖, 모듈 최상위 스코프로 이동
- 로직 변경 없음(순수 스코프 이동)

## 검증
- `node --check` 구문 검증 통과
- 원본과 diff 대조 → 함수 블록 위치 이동 외 변경 없음
- 중복 선언 없음 확인
