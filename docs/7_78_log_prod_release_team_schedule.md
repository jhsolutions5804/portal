## 방식 — 파일 통째 복사 금지 원칙 준수
테섭과 본섭은 Firebase 설정과 미반영 기능이 서로 다르므로(운영 원칙) **3자 병합**으로 변경분만 적용(기준 = 본섭 현재본과 가장 가까운 테섭 백업 원본). 본섭 설정·본섭 전용 변경은 유지.

## 사전 점검에서 발견한 사실 (기억과 달랐던 것)
- 월간 공수 안내 페이지 2개는 **이미 본섭에 반영**되어 있어 대상 제외.
- `pjt_roster`는 양쪽 저장소가 다른 작업으로 **이미 2.2.1**(팀장 계정 연결·모바일 카드·뒤로 가기 포함) — 손대지 않음(제 시험은 옛 버전 전제라 제외, 대신 기능 표식 코드 확인).
- 본섭 `gihoek`은 5.10.1 — 팀 단가 이중 저장이 없어 5.11.0 반영 필요했음.
- 본섭 SUP(`pjt_ph4`)에 `_usSetDone`이 없음 = 테섭에만 있는 미출시 “하루 넘기는 일정 완료체크 단일화”(SUP 종료 프로젝트) → 가져가지 않음.
- 본섭 홈에 다른 작업이 만든 연명부 카드가 있었음 → 대표님 결정에 따라 제거(진입은 PJT 관리 하위).
- 테섭 규칙에만 있는 `edoc_*` 열람 제한은 대표님 결정 대기 항목 → 본섭에 넣지 않음.

## 반영 중 잡은 결함
1. **본섭 규칙에서 `team_rates`가 포괄 규칙 제외 목록에서 빠져 있었음** — 그대로 게시했다면 팀 단가가 승인 직원 전원에게 공개될 뻔함(규칙 OR 평가). 게시 전 발견·수정.
2. 병합 충돌 3건(버전 주석, 연명부 카드, SUP 미출시 함수) — 자동 해결하지 않고 각각 판단해 수동 해결(README 참조).
3. 시험 도구 문제(무관): `node_modules` 미연결, 옛 버전 전제 시험(연명부 1.8.1·비밀번호 옛 위치 `_pw`), SUP 기대 함수 수 — 코드 결함 아님.
