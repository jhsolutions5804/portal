# 개발로그 — 근로자 연명부 v1.3.0 (③ 기존 인원 마이그레이션 도구 이전)

> 작성: 춘식이(Claude) · 2026-09-30 · 배포: portal-test (본섭 대기)

## 요청 · 경과

- 연명부 재편 ③단계: 월간 공수(`pjt_manday`)의 "기존 인원 마이그레이션" 도구를 연명부로 이전.
- 진행 전 확인: 월간 공수의 도구가 프로젝트별 명단을 이름 기준으로 묶어 마스터로 등록하고, 마스터 ID를 처음 발견된 명단 문서 ID로 정하며, 다른 프로젝트 문서는 마스터 ID로 재생성 후 기존 문서를 삭제하는 방식임을 코드로 확인.

## 설계

- 동작은 월간 공수와 동일하게 유지(현장 데이터 연동 호환), 안전장치만 추가.
- 추가·개선: 동명이인 경고 및 재확인, `writeBatch` 일괄 커밋, 조회 실패 프로젝트 경고, 미등록만 보기·건수 요약, 마스터 ID 충돌 방어.
- 이번 단계에서 월간 공수의 마이그레이션 버튼은 제거하지 않음(같은 `master_workers`를 다루므로 충돌 없음). ⑥ 단계에서 월간 공수 메뉴 정리와 함께 처리.
- 참고: 프로젝트 명단의 이름은 같은 ID의 마스터 이름으로 덮어써 표시되므로 ID 충돌 방어 코드는 정상 흐름에서는 동작하지 않는 안전장치.
