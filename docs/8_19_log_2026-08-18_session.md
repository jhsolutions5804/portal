## 작업 내용

**[PJT 관리] 기술인 명단 이름/생년월일 수정 불가 버그 + 생년월일 "10일→01일" 오입력 버그 수정**

- 증상 1: 명단 관리 패널에서 이미 등록된 인원의 이름·생년월일을 수정할 방법이 없음 (삭제만 가능)
- 증상 2: 생년월일 입력 시 "10"을 입력하려 해도 "01"로 들어감
- 원인: 생년월일이 비어있을 때만 1회용 `<input type="date">`가 나타나는 구조였고, 네이티브 date input의 세그먼트 자동확정 동작 때문에 두 자리 입력이 끊기는 문제
- 수정: 인원별 "수정" 버튼으로 이름+생년월일 인라인 편집 모드 추가, 생년월일은 텍스트 마스킹(YYYY-MM-DD) 방식으로 전환
- 검증: `node --check` 문법 검증, 프로덕션 diff 확인
- 배포: 프로덕션 직접 배포 (대표님 확인 후 진행)
