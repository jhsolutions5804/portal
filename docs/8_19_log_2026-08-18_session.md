**[PJT 관리] 기술인 명단 이름/생년월일 수정 불가 버그 + 생년월일 "10일→01일" 오입력 버그 수정**

- 수정: 인원별 "수정" 버튼으로 이름+생년월일 인라인 편집 모드 추가, 생년월일은 텍스트 마스킹(YYYY-MM-DD) 방식으로 전환
- 검증: `node --check` 문법 검증, 프로덕션 diff 확인
- 배포: 프로덕션 직접 배포 (대표님 확인 후 진행)

## 후속 — 견적 작성 시 합계금액 대신 공급가액 직접수정 (gihoek v5.3.12)

**요청**: 견적 작성 화면 하단 합계란에서 합계금액(부가세 포함) 대신 공급가액을 직접 수정하도록 변경.

**원인/배경**: 기존엔 합계금액을 입력받아 공급가 = 합계/1.1로 역산했는데, 나눗셈 반올림 오차가 발생할 수 있고 실무 흐름(공급가액 우선 확정)과도 맞지 않음.

**수정**: 합계란 UI를 "공급가액(직접 수정)" + 부가세·합계금액(자동계산, 읽기전용) 구조로 변경. `onSupplyEdit(v)`가 마지막 품목으로 차액을 흡수(÷1.1 역산 단계 제거).

**배포**: gihoek/index.html(5.3.10→5.3.12), index.html(버전배너, build 20260818b), 백업 backup/v5.3.12/gihoek/index.html

## 후속 (2) — 근로자 마스터 명부 퇴사처리 기능 추가 (pjt_manday v1.1.2, pjt v4.10.5)

**정정**: 배포 과정에서 버전코멘트가 실수로 4.10.4로 되돌아갔던 것을 4.10.6으로 정정.

## 후속 (4) — 지급예정서 공수연동 시 여러 프로젝트 합산 발행 (gihoek v5.3.15)

**요청**: 지급예정서를 공수 연동으로 작성할 때 Ph2·Ph4를 각각 따로 만들어야 하는데, 정산서 하나에 합쳐 발행할 수 있게 해달라는 요청.

**해결**: 공수 연동 카드에 프로젝트 다중 체크박스 추가. 2개 이상 선택 시 프로젝트별로 행이 나뉘어 공수·금액이 계산되고, 합계가 하나의 정산서로 발행됨. 항목표에도 프로젝트별로 구분되어 저장·인쇄됨. 1개만 선택하는 기존 방식은 그대로 유지.

**적용 범위**: 공수 연동 방식만. 공정 자동·수량 정산 방식은 견적서가 프로젝트별로 종속돼 있어 이번 범위에서 제외.

**배포**: gihoek/index.html(5.3.12→5.3.15), index.html(버전배너), 백업 backup/v5.3.15/gihoek/index.html

**증상**: 명단 관리에서 퇴사처리해도 일별 출역 체크리스트(기술인 출역 현황)엔 계속 남아 체크·공수입력이 가능했음.

**배포**: pjt/index.html(4.10.6→4.10.7), pjt_ph4/index.html, index.html(버전배너, PJT 5.3.4), 백업 backup/v5.3.16/*
