## 3. PC 초과근로 결재 (`edoc/index.html`) — 과제 ⑤

- 통상임금 로직 이식: `otCalcAnnualSalary`(사무직/현장직 구분), `otLoadWorkers`, `otGetWage`(연봉계약서 최신 조회 → `rate = round(total/209)`).
- `EDOC_TABS`·`DOC_CONFIG`·사이드바·탭바·전자결재 홈에 초과근로 등록. 홈에는 **`goTab('overtime')` 진입 버튼**(임베드 시 탭바/사이드바 숨김 대응).
- `renderOvertimeMain`(목록, 카드 클릭 시 `docDetail(d,'overtime')`로 상세+승인/반려)·`renderOvertimeWrite`(근로자 선택 → 통상임금·수당 자동)·`overtimeSave`.
- 결재선 고정: 작성 → 결재 **김종화 차장** → 회람 **김민서 대리**, 게시 없음.
- **승인 시 인사 자동 연동**: `docApprove`의 자동연동 체인에 `newStatus==='approved' && dtype==='overtime' && !rawData.linkedToOvertime` 추가 → `overtime` 컬렉션 addDoc + `linkedToOvertime:true`(중복 방지).

## 4. 모바일 전자결재 (`m/edoc.html`) — 과제 ③

- import 확장(doc/getDoc/getDocs/setDoc/addDoc/deleteDoc/serverTimestamp/query/orderBy/limit), `_me`(로그인 정보), `edoc_overtime` 구독.
- **결재(승인/반려)**: `canApprove`/`approveBtns`/`mobileApprove`. 결재선 단계 갱신 + status 전환(reviewing/approved). 관리자(admin=대표) 결재 대행. 초과근로 승인 시 인사 자동 연동.
- **작성 3종**: 업무일지(`renderDailyWrite`/`dailySaveM`), 연차(`renderLeaveWrite`/`leaveSaveM`), 초과근로(통상임금 이식 + `renderOvertimeWrite`/`overtimeSaveM`). 각 목록 우측 하단 `+` FAB.
- **삭제**: `canDelete`/`mobileDelete`. 관리자·작성자·미승인(draft/pending/reviewing) 문서 삭제 허용.
- 홈 타일에 초과근로 추가.

**버그 수정 (세션 후반)**
- 승인 완료 문서 결재버튼 숨김: `canApprove` 첫머리에 `status ∈ {approved,rejected,posted,done}` 이면 false.
- 퇴직원서 카드: `wide` → 일반 타일(`tile c8`)로 재직증명서 옆 배치(8타일 4×2).
- 06시 기준: `bizToday()` 헬퍼(오전 6시 전 전날) 추가, 작성 기본 일자 3곳 교체. 기존 `toISOString()`(UTC)도 로컬 기준으로 교정.

## 5. 로그인 게이트 (`m/auth-guard.js`, `index.html`)

**배경**: 모바일 서브페이지는 로그인 게이트가 없고 Firestore만 초기화 → 브라우저 IndexedDB에 남은 Firebase 세션으로 데이터가 자동으로 보임("자동 로그인"). 그러나 `jh_login_perms`(이름·부서·권한)는 메인 로그인 시에만 저장되므로 직접 진입 시 `_me`가 비어 승인/반려 등 권한이 잡히지 않음. 테섭·운영이 같은 origin(`github.io`)이라 세션도 공유됨.

**`m/auth-guard.js`**
- 로그인 게이트: `jh_login_perms` 없이 서브페이지 직접 진입 시 메인(`../index.html`)으로 유도. 들어가려던 페이지를 `sessionStorage.jh_return_to`에 저장.
- 무한루프 방지: `jh_gate_redir` 카운터. 2회 초과 시 통과(최소 화면은 뜨게). 정상 로그인 시 카운터 리셋.

**`index.html`**
- `showApp`: **복귀 경로(`jh_return_to`)가 있으면 UA와 무관하게** 원래 모바일 페이지로 복귀(PC UA에서 PC 홈으로 튕기던 문제 해결). 없으면 기존 UA 분기.
- splash fallback: 인증 콜백이 6초 내 미호출 시 로딩 강제 해제 + 로그인 화면(로그아웃 후 로딩 갇힘 대응).

## 핵심 학습
- **같은 origin(github.io) 세션 공유**: 테섭·운영이 IndexedDB/localStorage를 공유. 로그아웃 시 세션 꼬임 주의.
- **모바일 서브페이지 인증**: Firestore 접근은 세션으로 되지만 앱 로그인 정보(`jh_login_perms`)는 별도. 게이트로 일관성 확보.
- **임베드 시 탭바/사이드바 숨김**(`.portal-embed`): PC 전자결재에서 새 탭을 홈 진입 버튼으로도 노출해야 함.
- **통상임금**: `rate = round((basic+fixedOt+fixedNight+weekly)/209)`, 초과근로수당 = `round(rate×hours)`. PC 인사와 동일.
- **일자 기준 06시**: `if(getHours()<6) 전날`. 로컬(한국) 시각 기준. `toISOString()`은 UTC라 사용 금지.
