# 7.73. 개발로그 — 월간 공수 화면 폐지 (본섭)

> 2026-10-01 · 춘식이(Claude) · 대표님 질문 "월간공수는 언제 없애나?" → 전제 조건 충족 확인 후 즉시 반영

## 배경
- 월간 공수 기능은 이미 새 위치로 이전 완료: PJT 관리 › **근로자 연명부 › 월간 공수**(PJT별 합계·개인별 합계·개인별 공수표 PNG), 기획 › **정산 › 팀별 노무비**(팀 단가·노무비), 기존 인원 마이그레이션 도구도 연명부로 이전.
- 다른 세션이 테섭에서 폐지 안내 페이지와 메뉴 제거를 먼저 만들어 둠(pjt_manday 2.0.0, m/pjt_manday 2.0.0). 본섭은 옛 화면이 그대로 남아 있었음.

## 반영 내용 (본섭)
- `pjt_manday/index.html`, `m/pjt_manday.html`: **폐지 안내 페이지**(데이터·Firebase 사용 없음, 이전된 위치 안내)로 교체 — 즙겨찾기·옛 링크가 있어도 안내 후 이동.
- 포털 홈 `index.html`: 서브메뉴에서 월간 공수 항목 제거, 관련 조건문 정리, 경량 PJT 삽입 기준을 연명부 앞으로 변경(테섭과 동일 방식). **올리기 직전 최신 본섭 파일에 다시 적용**(다른 세션이 그사이 넣은 비밀번호 이전 변경 보존).
- 모바일 홈 `m/home.html`: 월간 공수 카드와 표시 코드 제거(연명부 카드는 관리자만 표시 유지).
- 검증: 모바일 홈 제거 전·후(관리자/일반직원) 렌더링, PC 서브메뉴·경량 PJT 삽입 시뮬레이션(경량 PJT가 연명부 앞에 정상 삽입), 4개 파일 문법·해시 대조. 본섭에 `pjt_manday` 참조 잔존 없음(주석 1곳 제외).
- 되돌리기: 제거 전 4개 파일을 `backup/v_manday_before_removal/`에 보관.
- 데이터: 근로자·공수 데이터는 그대로(화면만 폐지).
