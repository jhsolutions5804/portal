## 배경
`m/schedule.html`은 FAB·SUP·경량PJT 일정을 날짜별로 모아 보여주는 조회 전용 화면이었고, 항목을 누르면 `pjt.html?site=...`로 이동만 했다. PC 홈 일정(4.5.0/4.5.1)은 등록·수정·삭제·완료체크·할 일을 이미 지원. 모바일 `m/pjt.html`의 현장별 일정 탭에도 폼이 있으나 항목이 다름(메모 중심, 장소·참석자·종료시간·할 일 없음, 완료 필드 `doneAt`).

## 수정 (`m/schedule.html`, 1.0.1 → 1.1.0)
1. **권한**: `canEdit = admin || perms.pjt` (`jh_login_perms`). 없으면 조회 전용.
2. **목록**: 카드 왼쪽 체크박스(터치 영역 확장), 카테고리·할일 배지, 시간 범위(시작~종료), 장소 표시. 완료는 취소선.
3. **완료체크**: `setDoc(doc(db,...colPath,id),{done,doneUpdatedAt:serverTimestamp()},{merge:true})` — PC `_hscSetDone`과 동일. 저장 즉시 `onSnapshot`이 목록 갱신.
4. **등록/수정 폼(시트)**: PC 폼과 동일 항목(프로젝트·내용·카테고리 칩·시작/종료일·시작/종료시간·장소·참석자·등록자·할 일 토글). 등록 시 프로젝트 선택(진행 중만), 수정 시 프로젝트 고정. 저장 payload는 PC `saveHomeSched`와 동일 필드 + `savedAt`.
5. **상세 시트**: 전체 필드 + 수정/삭제/현장 열기. 삭제는 확인창 후 `deleteDoc`.
6. **컬렉션 매핑**: `fab→user_schedules`, `sup→ph4_schedules`, `reg_{id}→pjt_registry/{id}/schedules`. 종료된 고정 PJT는 등록 선택지에서 제외.
7. 추가 검증(PC엔 없음): 내용 필수, 같은 날 종료<시작 시간 차단, 종료일<시작일 보정.
8. 등록 후 해당 날짜로 화면 이동(수정 시엔 현재 날짜가 기간 내면 유지).
