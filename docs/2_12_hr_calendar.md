# 2.12. 인사 — 인사 캘린더 (hr 2.19.0 ~ 2.23.0)

> 최종 개정: 2026-10-01 (hr 2.23.0)

## 목적
면접·연봉제안서 회신·연봉협상·인사평가 일정을 한곳에서 관리한다. 공용 PJT 일정 캘린더와 분리하며, **지정 담당자 4명(김종화·김민서·김영희·송지훈)만** 조회·등록·수정·삭제할 수 있다.

## 접근 통제 (이중)
- 화면: 인사 모듈 자체가 관리자 전용. 인사 홈 왼쪽에 캘린더가 항상 표시된다.
- 서버(Firestore 규칙): `hr_calendar_access/config.emails`(소문자 이메일 배열)에 든 승인 계정만 `hr_calendar_events`·`hr_calendar_access` 읽기/쓰기. 관리자여도 명단 밖이면 거부. 일정 저장 시 구분(5종)·제목(1~200자)·날짜(YYYY-MM-DD) 형식을 검증.
- 명단 변경: 설정 문서 `hr_calendar_access/config`의 `emails`만 고치면 된다(코드 수정 불필요). Outlook 사서함 폴더 권한은 Exchange에서 별도 조정.

## 데이터
- `hr_calendar_events/{id}`: `type`(interview·offerreply·salarynego·eval·etc), `title`, `person`, `date`, `time`, `endTime`, `note`, `createdAt/By`, `updatedAt/By`, 자동 등록 건은 `source`(applicant·offer)·`srcId`.
- 자동 등록 일정 ID(고정, 중복 방지): 면접 `interview_<지원자ID>`, 제안서 회신 `offerreply_<지원자/근로자ID 또는 성명>_<제안일>`.

## 화면
- 인사 홈 2단(hr 2.20.0): 왼쪽 월간 캘린더(+ 날짜별 일정), 오른쪽 업무 흐름 메뉴(세로, 부제는 툴팁). 1100px 이하는 위아래로 쌓임. "크게 보기"는 전체 화면 탭(`hrcal`).
- 날짜 클릭 = 선택만(등록 창 안 열림). 하단에 그 날짜의 일정 목록, "＋ 이 날짜에 등록" 버튼, "n월 전체 보기".
- 공휴일(2025~2027, 노동절·제헌절·대체공휴일 반영) 빨간색 표시. 2028년 이후는 월력요항 발표 후 `_HC_HOL`에 추가.
- 연차(hr 2.22.0): 전자결재에서 게시된 연차를 `company_schedules`(분류 off)에서 읽기 전용으로 표시. 기간 연차는 주말·공휴일 제외. 수정은 전자결재 연차신청서에서. "연차 표시" 토글.

## 자동 등록 (hr 2.23.0)
- 채용 지원자 목록 "면접일"(날짜+시간) 입력 → 지원자 문서 `interviewAt` 저장 + 면접 일정 등록. 비우면 일정 삭제.
- 연봉 제안서 출력·이메일 발송 저장 시 "회신 기한"을 일정으로 등록.
- 캘린더 쓰기가 거부돼도 원래 기능(지원자 저장·제안서 출력)은 정상 동작. 면접일은 경고창, 제안서는 조용히 건너뜀.

## Outlook 반영
`outlook-sync` 서버 함수에 `syncHrCalendar` 추가(인사 일정 → hr-calendar@jhsol.kr 공유 사서함). 상세: `7_79_log_hr_calendar.md`.

## 검증
- 화면 테스트(jsdom) 60건 + 자동 등록 20건 + 지원자 목록 4건.
- 규칙: 에뮬레이터 62건(허용·차단·형식) + 변경 전/후 차분 493건(인사 캘린더 외 판정 변화 0건).
