# 7.70. 개발로그 — 모바일 월간 공수 제거 (portal-test)

> 2026-09-30 · 춘식이(Claude) · 대표님 확인 중 발견 → 테섭 반영 (본섭 미반영)

## 경위

- PC 월간 공수 메뉴 제거(`7_65_log_manday_removal.md`) 때 모바일은 “관리자용이라 유지”로 남겨 둠. 대표님이 모바일 화면(홈 카드·월간 공수 화면)에 월간 공수가 남아 있음을 지적 → 모바일도 제거.
- 화면의 합계 공수 0.0·참여 인원 0은 오류가 아님: 테섭 DB에 2026년 9월 공수 기록이 없음(FAB 마지막 2026-08, SUP 2026-07, 경량PJT 2026-08 — 읽기 전용 건수 확인).

## 변경

| 파일 | 내용 |
|------|------|
| `m/home.html` | 홈의 “월간 공수” 카드와 관리자 표시 스크립트 제거(div 균형·script 문법 OK) |
| `m/pjt_manday.html` v2.0.0 | 화면·Firebase 연결 제거, “PC 화면으로 이전” 안내 페이지(모바일 홈으로 돌아가기 버튼 포함) |

- 이전 위치 안내: 모바일 홈의 “PC 화면으로 보기” 전환 후 PJT 관리 > 근로자 연명부 > 월간 공수, 기획 > 정산 > 팀별 노무비.
- 이로써 모바일 월간 공수 팀 단가 수정(v1.1.0, `7_65`)은 불필요해짐(화면 자체가 폐지). 본섭은 아직 v1.0.0 화면이 남아 있어 팀단가 표시가 누락된 상태이며, 본섭에서는 이 제거 반영으로 해결됨.
- 모바일에는 연명부·정산 화면이 없으므로 모바일에서 팀별 금액을 보는 방법은 없어짐(PC 화면 전환 사용).
