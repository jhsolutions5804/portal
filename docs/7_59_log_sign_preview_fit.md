# 7.59. 개발로그 — 원격 서명 계약서 미리보기 잘림 수정

> 2026-09-30 · 춘식이(Claude)

- 증상: 서명 페이지 계약서 미리보기가 좌우로 잘려 보임(가로 스크롤바 있음, 왼쪽 글자 손실).
- 원인: 문서 HTML이 A4 고정폭(210mm≈794px)인데 본문이 flex 가운데 정렬이라, 미리보기 창(iframe)보다 넓으면 좌우로 넘쳐 왼쪽은 스크롤로도 볼 수 없음.
- 수정: `sign.html`에 `fitDocFrame`/`wireDocFrame` 추가 — 본문 실제 폭 기준으로 창 너비에 맞춰 축소(리사이즈 시 재계산). 폰에서 글자가 작아지므로 viewport 핀치 확대 허용(max-scale 1→5).
- 검증: Chromium 헤드리스로 실제 근로계약서 HTML을 폭 390/1280에서 렌더링, 좌우 잘림 없음 확인.
