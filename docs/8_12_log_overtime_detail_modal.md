# 8_12 · 초과근로 결재목록 노출 회귀 수정 + 클릭 상세보기 모달 (r1)

**작업일**: 2026-07-26
**대상**: `edoc/index.html`, `hr/index.html`
**요청 계기**:
1. 대표님이 재승인 후 데이터가 정상적으로 인사에 넘어왔음을 확인("좋아 데이터 잘 넘어가네")
2. 이어서 "인사 - 초과근로에서 해당 초과근로 클릭했을 때 상세 내용 보이게 하면 좋을 것 같아. 화면처럼 22일은 내용이 잘리는 것 같아서."

## 배경: 재승인 과정에서 발견된 회귀
정다애·이한영 4건을 재승인하려던 중, "작성된 초과근로 결재가 없습니다"라는 빈 화면을 만남. 07-23에 추가한 "본인 작성분만 표시" 필터가 관리자/결재자 본인의 결재 업무 자체를 막고 있었던 것.

## 수정 1 — `edoc/index.html`: 목록 노출 조건
`renderOvertimeMain()`을 다른 문서함(`renderDocList`)과 동일한 `canView` 표준 패턴으로 재작성:
- 관리자: 전체 조회 가능
- 본인 작성 문서
- 결재라인에 uid 또는 이름으로 지정된 건 (아직 승인 안 된 것 포함)

이로써 "타인 정보 비노출"과 "결재자는 결재 가능해야 함"을 동시에 충족.

## 수정 2 — `hr/index.html`: 클릭 상세보기 모달
사유 컬럼이 표 폭 제약으로 말줄임 처리되어 긴 내용이 잘려 보이던 문제. 세 테이블(PC 상세, 모바일 직원별 조회, 전체현황 상세) 모두 행 클릭 시 `otShowDetail(rowId)`가 사유 전문을 모달로 표시하도록 추가. `_otDetailCache`로 원본 데이터 캐시, 수정·삭제 버튼은 `event.stopPropagation()`으로 분리.
