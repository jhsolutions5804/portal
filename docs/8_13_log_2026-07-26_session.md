## 세션 흐름 요약

1. 5.0.0 본섭 배포 확인 중, PJT 홈 "종료된 프로젝트"에 남아있던 화성 17L 카드를 대표님이 지목 → 완전삭제 기능부터 추가(관리자 전용, 이중확인)
2. 대표님 질문: "진행 중인 프로젝트가 완결되면 워크스페이스는 어떻게 정리하는 게 좋을까?" → 데이터 보존(월간 공수 이력·공사일보 증빙 가치) 관점에서 삭제보다 종료(아카이브) 권장, FAB/SUP는 아직 종료 기능이 없다는 점 짚음
3. 대표님 지시: FAB/SUP도 미리 종료 가능하게 만들어두고, 종료된 프로젝트는 사이드바에 "종료 PJT" 새 폴더로 분리
4. `PJT_FIXED_BASE`(원본 보존) + `pjt_settings.status` 기반으로 FAB/SUP 종료·재개 구현
5. 사이드바 최하단에 "종료 PJT" 전용 메뉴/뷰 신설, 기존 PJT 홈의 종료 섹션은 이 뷰로 이전
6. 구현 중 함수 삽입 실수로 문법 오류 발생 → 즉시 발견·복구
7. portal-test 검증("잘 되네") → production 배포, 백업/문서/로그 마무리
