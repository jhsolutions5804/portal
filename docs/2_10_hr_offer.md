## 개요

연봉 또는 시급 중 **하나만** 입력하면 급여 구성(기본근로수당·주휴수당·월 지급계·연봉 총액)을 자동 계산해 A4 2쪽(제안서 + 회신서)을 새 창으로 출력하는 화면. 신규 입사·재계약·연봉 조정 세 가지 용도를 겸한다.

- 산식은 연봉계약서(`calcAnnualSalary`)와 동일. 연봉 입력 시 시급은 원 단위로 반올림하지 않고 소수 그대로 역산한다(v2.5.x "급여 입력 기준 선택"과 같은 방식) — 그 결과 12의 배수 연봉은 원 단위까지 입력값과 정확히 일치한다.
- DB에 아무것도 저장하지 않는다. 따라서 `2_9_hr_saved_doc_freeze.md`(저장 서류 양식 동결) 대상이 아니며, 계산식이 바뀌면 그냥 최신 로직으로 다시 계산될 뿐이다.

## 화면 구성 (`renderOfferMain` / `renderOfferForm`)

1. **제안 구분·대상자**: 신규 입사 / 재계약 / 연봉 조정. 근로자 선택 시 성명·소속·직급·입사일 자동 채움(재직자만 목록에 표시).
2. **계약 조건**: 고용형태, 적용기간, 소정근로시간, 수습기간.
3. **연봉·시급 입력**: 연봉 또는 시급 중 택1 + 비포괄/포괄 임금제 선택(포괄이면 고정연장·고정야간수당 입력칸 노출) + 기타 고정수당(명칭 자유입력).
4. **현재 조건**(재계약·조정일 때만): 근로자 선택 시 그 근로자의 최근 연봉계약서(`annual_contracts`)에서 연봉·직급·계약 종료일을 자동으로 가져와 채운다(종료일 다음날 ~ +1년으로 신규 적용기간도 자동 제안).
5. **기타 조건**: 급여 지급일, 상여, 제안일/회신기한, 특약사항, "별도지급 안내 포함" 체크박스.
6. **우측 계산 결과 패널**: 실시간으로 통상시급·기본근로수당·주휴수당·월 지급계·연봉 총액 표시. 최저시급 미달, 현재 연봉 대비 증감률 등 경고·안내 문구 포함.

## 별도지급(기술수당·여비교통비) 표시 (v2.7.0, 2026-09-23)

**요청**: 대표님 — 출력할 때 계약연봉 외에 급여명세서에 나오는 수당 항목도 보여줬으면 함.

기술수당·여비교통비는 매월 실제 조건(자격증 보유·이동거리)에 따라 급여명세서(`2_5_hr_payslip_r3.md`) 작성 시 계산되는 항목이라 연봉 총액에는 포함되지 않는다. 제안서 "별도 지급" 행에 아래처럼 표시한다:

- **기술수당**: 근로자를 선택했고 명부에 등록된 자격증이 있으면 `calcTechAllowance(worker)`(급여명세서와 동일 함수)로 실제 금액을 계산해 `보유 자격증 N개 × 단가 = 월 OOO원`으로 표시. 근로자 미선택이거나 자격증이 없으면 일반 안내문(1개당 단가, 상한 없음)으로 대체.
  - 단가는 `company_settings/salaryTable.techAllowancePerCert`(급여테이블 화면에서 관리) — `loadTechAllowanceConfig()`를 `renderOfferMain` 진입 시 백그라운드로 미리 불러온다.
- **여비교통비**: 금액이 매일 다르게 확정되므로 금액 대신 표준 요율표를 안내(개인차량 40km 이내 1만원/일, 40km 초과 2만원/일, 회사차량 1만원/일, 지방 장기출장 왕복교통비 실비·주 1회 한도) — 근로계약서 여비교통비 조항과 동일한 기준.
- 실시간 계산 패널에도 자격증 있는 근로자를 선택하면 "선택한 근로자는 기술수당 별도 대상입니다…" 안내 한 줄이 추가된다.
- "별도지급 안내 포함" 체크를 끄면 이 행 자체가 출력에서 빠진다(기존 동작 유지).

## 출력 문서 구조 (`offerBuildHtml`)

- **1쪽**: 제안 구분 → 대상자 정보 → 계약 조건 → 연봉 내역(표) → (재계약·조정만) 변경 내용 비교.
- **2쪽**: 기타 조건(급여지급·상여·4대보험·별도지급·특약) → 유의사항 5개 조항 → 제안자(회사) 서명란 → 절취선 → 연봉 제안 회신서(수락 여부·서명란).
- 새 창에서 "🖨 인쇄 / PDF로 저장" 버튼으로 인쇄 대화상자를 띄우며, 사용자가 "PDF로 저장"을 선택해 내려받는다(서버 저장 없음).

## 관련 함수 위치 (hr/index.html)

| 함수 | 역할 |
|------|------|
| `offerNewForm()` | 입력 폼 초기 상태 |
