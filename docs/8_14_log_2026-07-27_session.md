3. **`pjt_manday/index.html` (v1.0.1→v1.0.2)**: 페이지 자체에 로그인+관리자(`portal_users.admin`) 검증 추가, 검증 통과 전엔 어떤 Firestore 조회도 실행 안 되도록 수정. `?admin=1` 기반 급여노출 문제도 함께 해결. production 즉시 배포

5. `pjt/index.html`에 시험적으로 접근 게이트 + 자동 preload 2곳 지연 적용을 해봤으나(로컬), 더 안전한 방식으로 재검토 필요 판단 → 이번 세션에서는 production/portal-test 어디에도 배포하지 않음
