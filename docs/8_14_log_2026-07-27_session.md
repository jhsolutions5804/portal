## 세션 흐름 요약

1. 대표님이 스크린샷 3장과 함께 신고: "개인별 합계 생년월일 수정이 안 돼. 근로자 마스터 관리에서 입력한 게 자동으로 다 연동되면 좋겠는데. 상단에 미입력 인원도 남고."
2. `pjt_manday/index.html` 코드 확인 → 개인별 합계의 생년월일이 `master_workers`가 아니라 각 프로젝트 로컬 근로자 문서(`pjt_workers_fab`/`pjt_workers_ph4`/`pjt_registry/{id}/workers`)의 자체 `birth` 필드를 읽고 있음을 확인 (마스터 수정이 로컬 문서에 반영 안 됨)
3. 원인·해결 방향 보고 → 대표님 승인("응 그렇게 하고") + "본섭 먼저 해" 지시
4. `loadRoster()`에 `masterMap` 오버레이 파라미터 추가 — 근로자 ID가 마스터ID와 일치하면 이름·생년월일을 마스터 값으로 덮어써서 표시하도록 수정
5. `node --check` 문법 검증 통과 확인
6. 대표님 지시에 따라 portal-test 생략, **production 직접 배포**
7. 백업·기능문서(`4_4_pjt_manday.md`)·개발로그(`7_11_log_pjt_5_1_0.md`) 순으로 마무리
