# 7.83. 개발로그 — 퇴직원서 출력·퇴사 일정 반영·작업탭 먹통 수정 (hr 2.24.0 · 포털 build 20261001b)

> 2026-10-01 · 춘식이(Claude) · 대표님 지시: "승인 난 사직서는 퇴사일 일정 반영 / 퇴직원서 출력 / 인사 홈 갔다 돌아오면 퇴직원서가 동작하지 않음" → 테섭 확인 후 "본섭 반영하자"

## 변경
1. **퇴사 일정 자동 반영**: 인사 캘린더 구분 `resign` 신설, 승인된 퇴직원서 → `hr_calendar_events/resign_<원서ID>` 자동 등록·갱신·삭제 (`_hcSyncResign`). 상세는 `2_12_hr_calendar.md`.
2. **퇴직원서·휴직원서 출력**: 원서 상세 창 출력 버튼(`rrqPrint`), 팝업은 클릭 직후 먼저 열어 차단 방지.
3. **작업탭 먹통 수정(포털 index.html)**: 하단 탭 `휴직/퇴직 원서` 안에서 `인사 홈`을 누르면 iframe 자체가 인사 홈으로 이동해, 탭 이름은 원서인데 화면은 인사 홈인 상태가 됐고 메뉴를 다시 눌러도 `이미 열린 탭`으로 판단해 무반응이었다. 중복 탭으로 넘길 때 원래 iframe을 원래 화면(`goTab`)으로 되돌리도록 수정.

## 발견·교훈
- 테섭 확인 중 일정이 안 뜸 → 원인은 Firestore 규칙 `validHrEvent()`가 구분 5종만 허용(`resign` 거부, 화면엔 오류 없음). **일정 구분을 추가할 때는 규칙의 type 허용 목록을 함께 고친다.**
- 본섭 규칙은 테섭과 내용이 달라(edoc 열람 제한 등) 전문 복사 금지 — 해당 한 줄만 수정.

## 검증
